Проверка и поиск

ФункцияОписание
regex.match(s, pattern)Вся строка соответствует шаблону (true/false)
regex.search(s, pattern)Содержит ли подстроку, соответствующую шаблону (true/false)

Извлечение

var m = regex.findall("a=1, b=2", "(\\w)=(\\d)");
print(m[0][0]); // "a"
print(m[0][1]); // "1"

Без групп — массив совпадений. Одна группа — массив значений. Несколько групп — массив кортежей.

Замена и разделение

ФункцияОписание
regex.replace(s, pattern, repl)Замена ВСЕХ вхождений
regex.sub(pattern, repl, s, [count])Замена до count вхождений (-1 = все)
regex.split(s, pattern)Разделение по шаблону
regex.escape(s)Экранирование спецсимволов

Шаблоны используют синтаксис ECMAScript реализации std::regex. Строки преобразуются в UTF-8, но regex сопоставляет байты, поэтому классы вроде \w и границы символов не являются Unicode-aware. Ошибки шаблона в функциях модуля перехватываются; строковые методы .regexmatch(), .regexsearch() и другие могут выбросить исключение для некорректного шаблона.
