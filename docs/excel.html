Плагин Excel (XLSX)

Чтение и запись файлов XLSX — объектная модель XlsxDocument (нативная реализация на базе OpenXLSX)

RUEN

Главная / Плагины / Excel

⚠️ Плагин excel.dll — упрощённый, начального уровня. Для обычной работы с XLSX используйте Qt-версию: qt.XlsxDocument() (xlsx.html) или библиотеку xlsxedit.prg (automation.html).

Особенности

  • Нативная реализация (C++, OpenXLSX 0.5.1) — не зависит от Qt и внешних программ.
  • Поддержка UTF-8 имён файлов и русского текста в ячейках.
  • Чтение и запись: строки, целые и вещественные числа, логические, даты, пустые ячейки.
  • Работа с листами, объединение ячеек, ширины/высоты, скрытие строк/столбцов, свойства документа.
  • Чтение/запись только .xlsx (формат .xls, .csv не поддерживается).

Загрузка плагина

loadPlugin(file.apppath() + "/plugins/excel.dll");

Создание объекта

var doc = XlsxDocument();

print(doc.read(2, 2));  // 25

Полный пример

loadPlugin(file.apppath() + "/plugins/excel.dll");

var doc = XlsxDocument();
doc.create("test_output.xlsx");

var data = #[
    #["Имя", "Возраст", "Город"],
    #["Иван", 25, "Москва"],
    #["Мария", 28, "Казань"]
];
for (var i = 0; i < data.size(); i++)
    for (var j = 0; j < data[i].size(); j++)
        doc.write(i + 1, j + 1, data[i][j]);

doc.setColumnWidth(1, 25);
doc.setRowHeight(1, 20);
doc.mergeCells(5, 1, 5, 3);
doc.write(5, 1, "Итог");
doc.setDocumentProperty("Author", "Скрипт");
doc.save();
