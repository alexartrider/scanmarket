Форматирование

ФункцияОписание
datetime.strftime(dt, fmt)Дата → строка по формату
datetime.strptime(str, fmt)Строка → дата по формату; совместимый с Python вариант parse
datetime.datetostring(dt)Дата как строка
datetime.timetostring(dt)Время как строка
datetime.datetimetostring(dt)Дата+время как строка
var a = datetime.parse("2024-01-15");                      // автоопределение
var b = datetime.parse("15.01.2024", "%d.%m.%Y");       // строгий разбор по формату
var c = datetime.strptime("2024-01-15", "%Y-%m-%d"); // тот же форматный разбор

При заданном формате вся строка должна ему соответствовать; несовпадение или некорректная дата вызывает исключение. Используются спецификаторы разбора std::get_time; набор директив может зависеть от стандартной библиотеки C++.

Примеры

var now = datetime.now();
print(datetime.datetimetostring(now));

var d = datetime.makedatetime(2024, 12, 25, 10, 30);
print(datetime.strftime(d, "%d.%m.%Y %H:%M"));  // 25.12.2024 10:30

var future = datetime.addday(now, 30);
print(datetime.daysdiff(now, future));  // 30
