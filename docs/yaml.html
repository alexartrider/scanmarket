Модуль yaml

Работа с YAML — парсинг, сериализация и валидация (rapidyaml)

RUEN

Главная / yaml

Доступ

Модуль yaml доступен глобально без uses:

print(typeName(yaml));  // object

Функции

ФункцияОписание
yaml.parse(string)Разбор YAML-строки. Отображения → tuple, списки → array
yaml.load(path)Разбор YAML-файла (UTF-8) → значение
yaml.stringify(value)Значение → YAML-строка (block-стиль)
yaml.stringify(value, indent)YAML с указанным отступом (пробелы, по умолчанию 2)
yaml.save(value, path, [indent])Сериализация и запись в файл (UTF-8) → bool
yaml.validate(string)Проверка валидности YAML → true / false

Соответствие типов

YAMLScriptПримечание
mappingtuple #{"key": val}
sequencearray #[...]
stringstring
integer / floatint / double
true / falseint (1 / 0)Булевы значения хранятся как int
null / ~nullПустое значение тоже null

Строки при сериализации всегда заключаются в кавычки, что гарантирует корректный повторный разбор (включая строки вида "true", "1" и т.п.).

Примеры

Парсинг

var y = yaml.parse("name: Ivan\nage: 30");
print(y.name);  // Ivan
print(y.age);   // 30

Вложенные структуры

var data = yaml.parse("server:\n  host: localhost\n  ports:\n    - 80\n    - 443");
print(data.server.host);      // localhost
print(data.server.ports[1]);  // 443

Сериализация

var obj = #{"name": "Ivan", "age": 30, "tags": #[1, 2, 3]};
print(yaml.stringify(obj));   // блок-стиль, ключи и строки в кавычках
print(yaml.stringify(obj, 4));// отступ 4 пробела

Файлы

var cfg = yaml.load("config.yaml");
cfg["debug"] = true;
yaml.save(cfg, "config.yaml");
print(yaml.validate("{bad: [}"));  // false
