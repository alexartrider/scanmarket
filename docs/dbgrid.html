QDbGridView — Таблица данных

Просмотр и редактирование данных из базы данных в табличном виде

RUEN

Главная / QT / QDbGridView

Описание

QDbGridView — это виджет таблицы (наследник QTableView) для отображения и редактирования данных из базы данных. Поддерживает два режима работы:

  • Внешний DataSet — данные передаются из скрипта через setDataSet()
  • Внутренний DataSet — данные загружаются по SQL-запросу через open()

Формат JSON для columns

[
    {
        "field": "NAME",       // имя поля в БД
        "caption": "Наименование", // заголовок колонки
        "width": 150,          // ширина (по умолчанию 100)
        "visible": true,       // видимость (по умолчанию true)
        "align": 1,            // выравнивание: 1=Left, 2=Right, 4=Center
        "readOnly": false      // только чтение (по умолчанию false)
    }
]

Примеры

Внешний DataSet

var ds = db.open("SELECT * FROM users");
var grid = qt.create("QDbGridView", form);
grid.setDataSet(ds);
grid.columns = '[{"field":"ID","caption":"№","width":50},{"field":"NAME","caption":"Имя","width":200}]';
grid.align = "alClient";

Внутренний DataSet (SQL)

var grid = qt.create("QDbGridView", form);
grid.sql = "SELECT id, name, salary FROM employees WHERE department = 'IT'";
grid.autoOpen = true;
grid.columns = '[{"field":"id","width":50},{"field":"name","width":200},{"field":"salary","width":100,"align":2}]';
grid.align = "alClient";

Для формы из JSON с autoOpen: true подключите БД в верхнеуровневом коде формы: SQL-grid открываются после выполнения этого кода, но до обработчика formCreate (OnCreate). Именованные обработчики событий также должны быть объявлены в коде формы, чтобы подключиться при загрузке. Фазы инициализации подробно описаны в разделе жизненный цикл JSON-формы.

Обработка событий

grid.rowDoubleClicked = function(sender, row, rowData) {
    print("Выбрана строка: \(rowData["NAME"])");
};

grid.currentRowChanged = function(sender, row) {
    statusBar.showMessage("Строка \(row + 1) из \(sender.model.rowCount)");
};

currentRowChanged передаёт индекс строки; эта форма сигнала не зависит от конвертации QVariantMap. Если нужен способ чтения записи по индексу, можно выполнить отдельный SQL-запрос с тем же порядком сортировки и выбрать запись по индексу средствами конкретной БД. До исправления конвертации это обходной путь для currentRow().

Ручное открытие/обновление

grid.open();          // открыть по SQL
grid.refresh();       // обновить данные
var row = grid.currentRow();  // row["product_id"], row["name"]; NULL → null
grid.close();         // закрыть
