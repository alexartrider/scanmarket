Методы множеств (Set)

// Явное создание
var s1 = #set{1, 2, 3};
var s2 = #set{2, 3, 4};

// Автоопределение (простые значения → множество)
var s3 = #{1, 2, 3};

// difference/intersection изменяют исходное множество
// чтобы не портить s1 — предварительно clone():
print(s1.clone().difference(s2));        // {1} — s1 не изменился
print(s1.clone().intersection(s2));      // {2, 3}
print(s1);                              // {1, 2, 3}
МетодОписание
set.clear()Очистка
set.contains(val) / set.has(val)true если элемент есть
set.add(val)Добавление
set.remove(val)Удаление
set.isSubsetOf(other)true если подмножество
set.isSupersetOf(other)true если надмножество
set.symmetricDifference(other)Только в одном из двух (изменяет исходное значение)
set.equals(other)Равенство множеств
set.every(func) / set.some(func)Проверка условия
set.reduce(func, init)Свёртка

print(t1.keys());        // ["name", "age"]
print(t1.get("name"));   // "Иван"
t1.set("city", "Москва");

Важные нюансы

  1. concat, difference, intersection, subtract, merge изменяют исходное значение (мутируют) и возвращают его же. Для неразрушающего результата сначала вызовите clone().
  2. Методы DateTime работают через авто-приведение типов: строка "2026-06-28" или число 1687900000 будут автоматически преобразованы в дату.
  3. sort() без аргументов: числа по значению, строки лексикографически. С функцией: sort(function(a, b) { return a < b })
  4. unique() сначала сортирует, затем удаляет дубликаты. Порядок может измениться.
  5. forEach: для массивов — func(element), для кортежей — func(key, value).
