Плагин MAX Messenger

Бот-клиент для мессенджера MAX — подключение, отправка и получение сообщений через Long Polling

RUEN

Главная / Плагины / MAX

Общее

Плагин max.dll — интерфейс к официальному Bot API MAX (платформа platform-api2.max.ru). Поддерживает получение информации о боте, отправку текстовых сообщений и чтение входящих сообщений через Long Polling (GET /updates).

Токен бота присваивается при создании на платформе business.max.ru (раздел «Чат-боты» → ⋮ → Настройки). Токен передаётся заголовком Authorization — в URL он не вставляется.

Зависимости

Требуются OpenSSL 3: libssl-3-x64.dll, libcrypto-3-x64.dll (размещаются рядом с бинарником).

Загрузка плагина

loadPlugin("plugins/max.dll");

Создание объекта

var mx = maxclient();

Подключение

var mx = maxclient();

if (!mx.connect("ТОКЕН_ИЗ_BUSINESS.MAX.RU")) {
    print("Ошибка: \(mx.lastError())");
    return;
}

print("Подключено как @\(mx.botUsername)");

Отправка сообщения

По умолчанию send() отправляет сообщение пользователю по его user_id (ID можно получить из поля sender_id входящего сообщения): POST /messages?user_id=.

Третий аргумент mode задаёт тип получателя. Если он равен "chat" или "channel", recipientId трактуется как chat_id (чат или канал): POST /messages?chat_id=. Любое другое значение (или отсутствие аргумента) — отправка пользователю через user_id.

var mx = maxclient();
mx.connect("ТОКЕН");

// Отправка текста пользователю (user_id)
var ok = mx.send(12345678, "Привет!");
if (!ok) print("Ошибка: \(mx.lastError())");

// Отправка в чат/канал по chat_id
mx.send(987654321, "Привет, чат!", "chat");

Получение сообщений (Long Polling)

По умолчанию таймаут опроса — 30 секунд. MAX ограничивает использование Long Polling — для production-окружения рекомендуется Webhook.

var mx = maxclient();
mx.connect("ТОКЕН");
mx.setTimeout(30);

// Ожидание сообщения (блокирующий вызов до таймаута)
var msg = mx.recv();
if (!msg.isnull()) {
    print("type:    \(msg.type)");
    print("от:      \(msg.sender_first_name) \(msg.sender_last_name) (id:\(msg.sender_id))");
    print("текст:   \(msg.text)");
}

// Опрос в цикле с ответом на "ping"
for (var i = 0; i < 5; i++) {
    var m = mx.recv();
    if (!m.isnull() && m.text == "ping") {
        mx.send(m.sender_id, "pong");
    }
}

SSL-сертификаты

// Проверка цепочки сертификатов выключена по умолчанию
print(mx.setVerify());  // 0

// Включить проверку
mx.setVerify(1);

// Свой файл CA (например, сертификат Минцифры для доменов max.ru)
mx.setCA("C:/certs/cacert.pem");

Полный пример: бот-эхо

loadPlugin("plugins/max.dll");

var mx = maxclient();
mx.setVerify(1);
mx.setTimeout(30);

// Токен из business.max.ru → Чат-боты → Настройки
if (!mx.connect("ТОКЕН")) {
    print("Ошибка подключения: \(mx.lastError())");
    system.exit(1);
}

print("Бот @\(mx.botUsername) запущен. Напишите ему что-нибудь в MAX.");

while (mx.connected) {
    var msg = mx.recv();

    if (msg.isnull()) {
        continue;  // таймаут опроса — повторим
    }

    print("\(msg.sender_first_name): \(msg.text)");

    if (msg.text == "/stop") {
        mx.disconnect();
        break;
    }

    // Ответ отправителю
    mx.send(msg.sender_id, "Вы написали: \"\(msg.text)\"");
}
