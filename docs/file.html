Чтение

ФункцияОписание
file.read(path, [enc])Читает как строку (по умолчанию кодировка определяется автоматически; BOM пропускается, если он есть)
file.readlines(path)Массив строк: делит по \n, у каждой строки срезает завершающий \r (CRLF читается корректно). Пустые строки сохраняются; завершающий перевод строки НЕ даёт пустого хвостового элемента (как Python str.splitlines()); пустой файл → []. ⚠️ str.split(text, "\n") (regex) для завершающего перевода строки возвращает хвостовую пустую строку — для построчной работы используйте readlines
file.readmeta(path)Читает файл и возвращает кортеж #{"text", "enc", "bom"}: текст + определённая кодировка (file.ENC_*) + наличие BOM. Пустой/отсутствующий файл → enc=UTF8_NO_BOM, text=""; нераспознанная кодировка (ENC_UNKNOWN) → text="" (содержимое доступно через file.readbytes)
file.readbytes(path)Массив int64 значений (каждый элемент — байт)

Автоопределение кодировки (общее для read и readmeta): BOM (UTF-8/UTF-16 LE/BE) → по BOM; иначе валидный UTF-8 → UTF8_NO_BOM (в т.ч. чистый ASCII — безопасно, ASCII ⊂ UTF-8); иначе похожий на CP1251 → CP1251; иначе UNKNOWN. UTF-16 LE без BOM определяется по нулевым байтам. BOM пропускается при чтении только если он фактически есть (BOM-less UTF-16 декодируется без смещения).

Запись

file.write() и file.append() по умолчанию пишут UTF-16 LE (сохранено для совместимости). Для исходников и конфигов используйте file.writeatom() — по умолчанию UTF-8 без BOM.

ФункцияОписание
file.write(path, text, [enc])Запись строки (UTF-16 LE по умолчанию)
file.writebytes(path, data)Запись массива байт или ByteArray
file.append(path, text, [enc])Дописывание в конец файла
file.writeatom(path, text, [opts])Атомарная запись: временный файл + замена. По умолчанию UTF-8 без BOM. → true, при ошибке — исключение
file.writeLines(path, arr, [opts])Атомарная запись массива строк (join + \n в конце). Аналог Python-цикла записи строк
file.appendLines(path, arr, [opts])Атомарное дописывание массива строк в конец файла

Опции file.writeatom

file.writeatom(path, text, #{
    "enc":       "utf8" | "utf8-nobom" | "utf16" | "cp1251",  // по умолчанию utf8-nobom
    "overwrite": 1 | 0,          // 0 — бросить исключение, если файл уже существует
    "backup":    1 | "путь.bak", // создать резервную копию до замены (по умолчанию без бэкапа)
    "verify":    1 | 0           // прочитать файл после замены и сверить содержимое (по умолчанию 1)
});

При ошибке верификации файл откатывается из резервной копии, если она была включена.
