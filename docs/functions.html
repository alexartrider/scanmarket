SQLite (модуль sqlite)

⚠️ Упрощённый модуль, начального уровня. Для полноценной работы (параметризация, транзакции, read-only) используйте Qt-версию — модуль db (db.html).

Подробная справка: Модуль sqlite

ФункцияОписание
sqlite.open(path)Открыть SQLite-файл
sqlite.memory()Создать базу в памяти
sqlite.version()Версия SQLite
var db = sqlite.memory();
db.exec("create table t(id integer primary key, value text)");
db.exec("insert into t(value) values (?)", #["test"]);
print(db.scalar("select value from t"));
db.close();

Типы и интроспекция

ФункцияОписание
type(val)Числовой код типа: 0=null, 1=int, 2=double, 3=string, 4=object, 5=array, 6=tuple, 7=set
typeName(val)Имя типа как строка (нижний регистр): "null", "int", "string", "array"...
size(val)Размер (длина строки, кол-во элементов в коллекции)
empty(val)true если пустое
propertyNames(obj)Имена свойств объекта
exists(name)Существует ли переменная
propertyExists(obj, name)Существует ли свойство объекта
methodExists(obj, name)Существует ли метод объекта
hash(val)Хеш-значение
errorInfo()Диагностика последнего перехваченного исключения: #{"kind","message","file","line","col","value"} или null. Заполняется в блоке catch
type(42)              // 1 (int)
type("hello")        // 3 (string)
type(#[1,2])         // 5 (array)
typeName(42)         // "int"
typeName("hello")    // "string"

// Проверка типа через type():
if (type(val) == 3) print("это строка");
if (type(val) == 0) print("это null");

Примечание: Глобальные функции isnull(), isstring(), isint() и т.д. не существуют. Используйте type(val) или метод .isnull() для объектов.

Работа с коллекциями

ФункцияОписание
toarray(val)Преобразование в массив
push(arr, val)Добавление элемента
pop(arr)Извлечение последнего элемента
clear(arr)Очистка коллекции
sorted(set)Сортировка (возвращает set)
reversed(arr)Реверс (возвращает array)
range(start, [end], [step])Генерация числового диапазона (возвращает set)
foreach(arr, func)Вызов функции для каждого элемента
map(arr, func)Преобразование каждого элемента
filter(arr, func)Фильтрация по условию

var arr = #[30, 10, 20];
sorted(arr);        // set: {10, 20, 30}  — НЕ массив!
reversed(arr);      // array: [20, 10, 30]

range(5);           // set: {0, 1, 2, 3, 4}
range(2, 5);        // set: {2, 3, 4}

var doubled = map(arr, function(x) { return x * 2; });
var evens = filter(arr, function(x) { return x % 2 == 0; });
var total = reduce(arr, function(acc, x) { return acc + x; }, 0);

Используется printf-стиль (не {0}!):

JSON (модуль json)

Подробная справка: Модуль json

ФункцияОписание
json.parse(string)Разбор JSON-строки → tuple (объект) или array
json.stringify(value, [pretty])Значение → JSON-строка
json.stringify(value, true, [indent])Красивый вывод с отступами (по умолчанию 4 пробела)
json.validate(string)Проверка валидности JSON → true / false
var data = json.parse('{"name": "Иван", "age": 30}');
print(data.name);  // Иван

var str = json.stringify(data, true);
print(str);  // красивый вывод с отступами

print(json.validate('{"a":1}'));  // true

YAML (модуль yaml)

Подробная справка: Модуль yaml

ФункцияОписание
yaml.parse(string)Разбор YAML-строки → tuple (mapping) или array (sequence)
yaml.load(path)Разбор YAML-файла → значение
yaml.stringify(value, [indent])Значение → YAML-строка (block-стиль, отступ 2 по умолчанию)
yaml.save(value, path, [indent])Сериализация и запись в файл
yaml.validate(string)Проверка валидности YAML → true / false
var data = yaml.parse("server:\n  host: localhost\n  port: 8080");
print(data.server.host);  // localhost

print(yaml.validate("a: 1"));  // true
