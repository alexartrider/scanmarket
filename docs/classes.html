Stack (LIFO)

Создание: конструктор Stack() или литерал #stack{}

var s = Stack();
s.push(10);
s.push(20);
s.push(30);
print(s.top());    // 30
print(s.pop());    // 30
print(s.peek());   // 20
print(s.size());   // 2
Свойство/МетодОписание
s.size()Количество элементов
s.empty()true если пуст
s[i]Доступ по индексу (0 = верх)
s.push(val)Добавление наверх
s.top()Возврат верхнего без удаления
s.peek()Алиас top()
s.pop()Удаление и возврат верхнего
s.clear()Очистка
s.resize(n)Изменение размера (добавление/удаление)
s.reserve(n)Резервирование памяти

Queue (FIFO)

Создание: конструктор Queue() или литерал #queue{}

var q = Queue();
q.push(10);
q.push(20);
q.push(30);
print(q.front());  // 10
print(q.pop());    // 10
print(q.back());   // 30
МетодОписание
q.push(val)Добавление в конец
q.push_front(val)Добавление в начало
q.pop()Удаление первого
q.pop_back()Удаление последнего
q.front()Первый элемент
q.back()Последний элемент
q[i]Доступ по индексу
q.size()Количество элементов
q.empty()true если пуст
q.resize(n)Изменение размера очереди

PriorityQueue (max-heap)

Создание: конструктор PriorityQueue() или литерал #priorityqueue{}

Чем больше число приоритета — тем выше приоритет (pop извлекает максимальный).

var pq = PriorityQueue();
pq.push("low", 1);
pq.push("high", 10);
pq.push("medium", 5);
print(pq.peek());  // "high"
print(pq.pop());   // "high" (приоритет 10)
print(pq.pop());   // "medium" (приоритет 5)
МетодОписание
pq.push(val, priority)Добавление с приоритетом (по умолчанию 0)
pq.pop()Извлечение с наивысшим приоритетом
pq.peek()Просмотр без удаления
pq.size()Количество элементов
pq.empty()true если пуст
pq.clear()Очистка

Dictionary (case-sensitive)

Создание: конструктор Dictionary() или литерал #dictionary{}

var d = Dictionary();
d.set("name", "Иван");
d.set("age", 25);
print(d.get("name"));    // "Иван"
print(d.has("age"));     // true
print(d.size());           // 2

// Доступ через точку
print(d.name);            // "Иван"

// Проверка ключа
print(d.contains("name"));  // true
МетодОписание
d.size()Количество пар
d.empty()true если пуст
d.set(key, val)Установка значения
d.get(key)Получение значения
d.getdefault(key, def)С значением по умолчанию
d.has(key)Наличие ключа
d.contains(key)Алиас has()
d.remove(key)Удаление
d.pop(key)Удаление и возврат
d.keys()Массив ключей
d.values()Массив значений
d.items()Массив кортежей [key, value]
d.update(other)Обновление из другого словаря
d.clear()Очистка

DictionaryCI (case-insensitive)

Создание: конструктор DictionaryCI() или литерал #dictionaryci{}

Аналог Dictionary, но ключи без учёта регистра.

var d = DictionaryCI();
d.set("Name", "Иван");
print(d.get("name"));  // "Иван" — регистр не важен

StringSet

Множество уникальных строк (регистрозависимое). Хранение и проверка наличия с учётом регистра.

Создание: конструктор StringSet() или со списком значений StringSet("a", "b")

var set = StringSet();
set.add("apple");
set.add("Apple");  // другой элемент (регистр важен)
print(set.size());        // 2
print(set.has("apple")); // true
print(set.has("APPLE")); // false
МетодОписание
set.size()Количество элементов
set.empty()true если пуст
set.add(val)Добавление (true если добавлен, false если уже был)
set.insert(val...)Добавление нескольких значений
set.remove(val)Удаление (true если был)
set.discard(val)Удаление (аналог remove)
set.has(val)Наличие элемента
set.contains(val)Алиас has()
set.toList()Массив всех элементов
set.values()Алиас toList()
set.pop()Удаление и возврат произвольного элемента
set.update(other)Объединение с другим множеством
set.clear()Очистка

StringSetCI (case-insensitive)

Множество уникальных строк без учёта регистра. "Name", "NAME" и "name" — один элемент.

Создание: конструктор StringSetCI() или со списком значений StringSetCI("a", "b")

var set = StringSetCI();
set.add("apple");
set.add("APPLE");  // тот же элемент (регистр не важен)
print(set.size());        // 1
print(set.has("Apple")); // true

API аналогичен StringSet.

Mutex

// критическая секция
m.unlock();
Свойство/МетодОписание
m.lockedtrue если заблокирован
m.lock()Блокировка
m.tryLock()Попытка блокировки (true/false)
m.unlock()Разблокировка

LockGuard (RAII)

Автоматическая разблокировка при выходе из scope.

var m = Mutex();
{
    var guard = LockGuard(m);
    // критическая секция
    guard.dismiss();  // необязательно: отпустить раньше
}  // автоматическая разблокировка

synchronized()

var m = Mutex();
synchronized(m, function() {
    // атомарный блок
    sharedData += 1;
});
