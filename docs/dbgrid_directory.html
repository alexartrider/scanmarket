QDbDirectoryView — Проводник

Иерархический или плоский просмотр данных с навигацией по папкам

RUEN

Главная / QT / QDbDirectoryView

Описание

QDbDirectoryView — комплексный виджет для навигации по иерархическим данным (папки, деревья). Включает в себя:

  • Таблицу данных (QDbGridView) для отображения записей
  • Панель навигации «хлебные крошки» для отображения текущего пути
  • Переключатель режимов — иерархический или плоский

Таблица должна содержать поля:

  • rowid — уникальный идентификатор строки
  • name — наименование
  • folder — 1 если папка, 0 если файл/запись
  • parent — ID родительской папки (-1 для корня)

Примеры

Базовый проводник

var dir = qt.create("QDbDirectoryView", form);
dir.tableName = "files";
dir.directoryMode = true;
dir.viewMode = 0;  // Hierarchical
dir.columns = '[
    {"field":"rowid","caption":"ID","width":50},
    {"field":"name","caption":"Наименование","width":300},
    {"field":"folder","caption":"Тип","width":80}
]';
dir.align = "alClient";
dir.autoOpen = true;

Плоский режим (без навигации)

var dir = qt.create("QDbDirectoryView", form);
dir.tableName = "employees";
dir.directoryMode = false;
dir.align = "alClient";
dir.open();

Обработка событий

// Двойной клик — открыть папку или файл
dir.rowDoubleClicked = function(sender, row, rowId, isFolder) {
    if (isFolder) {
        sender.navigateTo(rowId);
    } else {
        print("Открыть файл: \(rowId)");
    }
};

// Смена папки
dir.folderChanged = function(sender, folderId, folderName) {
    form.windowTitle = "Проводник — \(folderName)";
};

Ручное управление навигацией

dir.open();                 // открыть
dir.navigateTo(42);         // войти в папку 42
dir.navigateUp();           // вернуться назад
dir.navigateToRoot();       // в корень
var id = dir.currentRowId();  // текущий ID
dir.refresh();              // обновить
