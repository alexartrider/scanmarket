Запуск без GUI (headless)

Для автоматизации и CI можно запускать qodeqt без графической сессии через символический платформенный плагин offscreen (развёрнут в qt/bind/platforms и qt/bin/platforms). Формы (dialog.newform), таблицы (dialog.newtable, QRXLWidget) и loadFromMemory работают без окна.

// 1. Передать платформу дочернему процессу (наследуется через окружение):
file.setenv("QT_QPA_PLATFORM", "offscreen");
var res = system.execArgv(#[qodeqt, script, outFile], #{"timeout": 60000});

// 2. В дочернем скрипте проверить реальную платформу:
if (str.toString(qt.platformName()) != "offscreen") { … }

// Либо вручную из консоли:
//   set QT_QPA_PLATFORM=offscreen && qodeqt.exe script.prg

Обработка событий (сигналов QT)

1. Дизайнер (JSON)

В JSON-файле формы события указываются с оригинальными именами сигналов Qt. Ключ — имя сигнала, значение — имя функции-обработчика в скрипте.

{
    "events": {
        "clicked": "qPushButton1_clicked",
        "formCloseQuery": "Form1_formCloseQuery"
    }
}
function qPushButton1_clicked(Sender, checked) {
    form.close();
}

function Form1_formCloseQuery(Sender) {
    return form.qCheckBox1.checked;
}

2. Скрипт (динамическое подключение)

Для динамического подключения/отключения обработчиков используется свойство с оригинальным именем сигнала. Имя функции может быть любым, включая анонимные функции (лямбды).

widget.имяСигнала = функцияОбработчик;

Примеры

// Именованная функция
function handleClick(sender, checked) {
    print("Кнопка нажата!");
}
btn.clicked = handleClick;

// Анонимная функция (лямбда)
btn.clicked = function(sender, checked) {
    print("Клик!");
};

// Лямбда без аргументов
timer.timeout = function() {
    print("Таймер сработал");
};

// Удаление обработчика
btn.clicked = null;

// Динамическая смена обработчика
form.formCloseQuery = form.qCheckBox2.checked
    ? Form1_formCloseQuery
    : function(Sender) { print("lambda"); };

Первым аргументом в функцию всегда передаётся sender (объект, вызвавший сигнал). Далее следуют аргументы сигнала Qt (bool, int, QString и т.д.), которые автоматически конвертируются в типы скрипта.

Жизненный цикл JSON-формы

При загрузке RuntimeForm синхронно выполняются фазы:

  1. Создаются виджеты формы и применяются их свойства.
  2. Выполняется верхнеуровневый код Script-модуля формы (EvalModule).
  3. Подключаются события формы и виджетов.
  4. Открываются SQL-таблицы QDbGridView с autoOpen: true.
  5. Вызывается обработчик formCreate (OnCreate).

Порядок сохраняется для совместимости. Подключение БД, необходимое для автоматического открытия таблиц, должно завершиться в верхнеуровневом коде до шага autoOpen; подключение в OnCreate слишком позднее. Именованные функции обработчиков следует объявить в коде формы: они должны существовать к фазе подключения событий. В OnCreate таблицы autoOpen уже открыты. Отдельные хуки/управляемая отложенная активация здесь не добавлены: они создавали бы новую семантику и не нужны, если соблюдать текущие явные фазы. 

// Верхнеуровневый код выполняется до autoOpen
db.connect(db.QSQLITE, "app.sqlite");

function formCreate(Sender) {
    // К этому моменту SQL-grid с autoOpen уже открыты
    print(form.products.currentRowIndex());
}

function products_currentRowChanged(Sender, rowIndex) {
    // rowIndex — индекс строки с нуля
}

Подробности о SQL-grid и currentRow() см. в разделе QDbGridView.

Пример приложения

var app = qt.app();
var mainWindow = qt.create("QMainWindow");
mainWindow.windowTitle = "Моё приложение";
mainWindow.resize(800, 600);
mainWindow.enableLayoutManager();

var central = qt.create("QWidget", mainWindow);
mainWindow.setCentralWidget(central);

var btn = qt.create("QPushButton", central);
btn.text = "Нажми меня";
btn.align = "alTop";

var textEdit = qt.create("QPlainTextEdit", central);
textEdit.align = "alClient";

function onBtnClicked(sender) {
    dialog.showmessage("Вы нажали кнопку!");
}
btn.clicked = onBtnClicked;

var menuBar = mainWindow.menuBar;
var fileMenu = menuBar.addMenu("Файл");
fileMenu.addAction("Выход").triggered = function(sender) {
    app.quit();
};

mainWindow.show();
qt.run();
