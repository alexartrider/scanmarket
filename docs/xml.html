Модуль xml

Работа с XML — парсинг, создание и модификация документов (pugixml)

RUEN

Главная / xml

Доступ

Модуль xml доступен глобально без uses:

print(typeName(xml));  // object

Функции модуля

ФункцияОписание
xml.parse(string)Разбор XML-строки → XmlDocument
xml.load(path)Загрузка XML из файла → XmlDocument
xml.create(rootName)Создание нового документа с корневым элементом → XmlDocument

Методы XmlDocument

МетодОписание
doc.child(name)Первый дочерний элемент по имени → XmlNode
doc.children()Все дочерние элементы корня → массив XmlNode
doc.print()Сериализация документа в строку (с отступами)
doc.save(path)Сохранение в файл (с отступами по умолчанию)
doc.save(path, false)Сохранение без отступов
doc.set_root(name)Добавление корневого элемента → XmlNode

Методы XmlNode

МетодОписание
node.name()Имя элемента
node.value()Значение атрибута value (или пустая строка)
node.set_value(val)Установка значения
node.text()Текстовое содержимое элемента
node.set_text(val)Установка текстового содержимого
node.attribute(name)Значение атрибута по имени (или null)
node.set_attribute(name, val)Установка или создание атрибута
node.child(name)Первый дочерний элемент по имени → XmlNode
node.children()Все дочерние элементы → массив XmlNode
node.parent()Родительский элемент → XmlNode
node.next_sibling()Следующий соседний элемент → XmlNode
node.prev_sibling()Предыдущий соседний элемент → XmlNode
node.append_child(name)Добавление дочернего элемента → XmlNode
node.remove_child(name)Удаление дочернего элемента по имени → bool
node.attributes()Все атрибуты → массив кортежей #{"name": ..., "value": ...}
node.empty()true если элемент пуст
node.print()Сериализация поддерева в строку (с отступами)

Примеры

Парсинг XML

var doc = xml.parse("<root><name>Ivan</name><age>30</age></root>");
print(typeName(doc));  // object

var root = doc.child("root");
print(root.name());           // root
print(root.child("name").text());  // Ivan
print(root.child("age").text());   // 30

Вывод документа

print(doc.print());
// <?xml version="1.0"?>
// <root>
//     <name>Ivan</name>
//     <age>30</age>
// </root>

Создание XML

var doc = xml.create("catalog");
var root = doc.child("catalog");

var item = root.append_child("item");
item.set_attribute("id", "1");
item.append_child("title").set_text("Книга");
item.append_child("price").set_text("500");

print(doc.print());

Загрузка из файла

var doc = xml.load("data.xml");
var items = doc.child("root").children();
for (var item : items) {
    print(item.name() + ": " + item.text());
}

Сохранение в файл

doc.save("output.xml");         // с отступами
doc.save("output.xml", false);  // без отступов

Работа с атрибутами

var node = doc.child("root").child("item");
print(node.attribute("id"));  // значение атрибута id

var attrs = node.attributes();
for (var a : attrs) {
    print(a.name + "=\"" + a.value + "\"");
}

Навигация по дереву

var node = doc.child("root").child("item");
var parent = node.parent();
var next = node.next_sibling();
var prev = node.prev_sibling();
