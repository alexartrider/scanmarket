Модуль OLE — Компонентная модель (Windows)

Доступ к COM-объектам через IDispatch

RUEN

Главная / OLE

Функции

ФункцияОписание
ole.create(progId)Создание COM-объекта по ProgID (например, "Excel.Application")
ole.getActive(progId)Получение уже запущенного COM-объекта
ole.isAvailable(progId)Проверка доступности COM-класса (bool)

Пример

var excel = ole.create("Excel.Application");
excel.Visible = true;
var wb = excel.Workbooks.Add();
var sheet = wb.Sheets(1);
sheet.Cells(1, 1).Value = "Привет";
wb.SaveAs("C:\\test.xlsx");
excel.Quit();

Свойства и методы OLE-объекта

Доступ к свойствам и методам COM-объекта — через точечную нотацию. Имена без учёта регистра.

Свойства

obj.PropertyName           // чтение
obj.PropertyName = value   // запись

Методы

obj.MethodName(arg1, arg2)  // вызов метода

Примеры

// Word
var word = ole.create("Word.Application");
word.Visible = true;
var doc = word.Documents.Add();
doc.Content.Text = "Hello, World!";
doc.SaveAs2("C:\\doc.docx");
word.Quit();

// Получение активного экземпляра
var excel = ole.getActive("Excel.Application");
if (excel) {
    print("Excel уже запущен");
}

Ограничения

  • Доступно только на Windows (OLE/COM)
  • Массивы конвертируются в SAFEARRAY (1D и 2D)
  • Тип VT_DISPATCH возвращается как OLE-объект
  • 3D+ массивы не поддерживаются
