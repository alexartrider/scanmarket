Поиск и проверка

str.find() — есть (в отличие от старой документации); str.rpos не существует, поиск с конца — str.rfind().

ФункцияОписание
str.find(s, sub)Есть ли вхождение → true / false (подстрока как литерал, без regex)
str.pos(s, sub)Позиция первого вхождения или -1
str.rfind(s, sub, [start])Позиция последнего вхождения (поиск от start) или -1
str.count(s, sub)Количество вхождений (неперекрывающихся; для пустой подстроки — len+1, как в Python)
str.positions(s, sub)Массив позиций всех неперекрывающихся вхождений (пустой, если нет)
str.startswith(s, prefix)Начинается ли строка с prefix
str.endswith(s, suffix)Заканчивается ли строка на suffix
str.findany(s, chars)Позиция первого символа из набора chars
str.findnot(s, chars)Позиция первого символа НЕ из набора chars
var s = "Hello World";
print(str.find(s, "World"));    // true
print(str.pos(s, "World"));     // 6
print(str.rfind("a-b-a", "a"));  // 4
print(str.count(s, "l"));       // 3
print(str.positions("xxyyxxyxx", "xx"));  // [0, 4, 7]
print(str.startswith(s, "He"));  // true
print(str.endswith(s, "ld"));    // true

Заполнение и выравнивание

Примечание: третий аргумент pad — числовой код символа (int), не строка:

ФункцияОписание
str.pad(s, width, charCode)Дополнение справа. charCode — int код символа
str.zfill(s, width)Дополнение нулями слева
str.center(s, width, [fill])Центрирование
str.ljust(s, width, [fill])Выравнивание по левому краю
str.rjust(s, width, [fill])Выравнивание по правому краю
// Дополнение точками (46 — код '.'):
print(str.pad("hi", 5, 46));   // "hi..."

print(str.zfill("42", 5));      // "00042"
print(str.center("hi", 6));    // "  hi  "
