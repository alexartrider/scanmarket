Диалоговые функции

ФункцияОписание
dialog.showmessage(text, [parent])Диалоговое окно с текстом и кнопкой OK
dialog.yesno(text, [parent])Вопрос Да/Нет. Возвращает "yes" или "no"
dialog.yesnocancel(text, [parent])Вопрос Да/Нет/Отмена. Возвращает "yes", "no" или "cancel"
dialog.inputbox(title, label, default)Строка ввода. Возвращает введённый текст
dialog.inputquery(title, labels, defaults)Многострочный ввод (массивы или кортеж)

Примеры

dialog.showmessage("Привет!");

var answer = dialog.yesno("Удалить файл?");
if (answer == "yes") { ... }

var name = dialog.inputbox("Введите имя", "Имя:", "Иван");
var vals = dialog.inputquery("Данные", #{"Имя": "", "Возраст": "25"});
if (vals) print(vals.Имя);
