SQLite модуль

Нативный встроенный SQLite без зависимости от QtSql и внешнего SQLite DLL

RUEN

Главная / SQLite

⚠️ Упрощённый модуль (начального уровня): нативный встроенный sqlite — базовый набор (exec/query/scalar…) без развития. Для автоматизации и полноценной работы используйте Qt-версию — модуль db: параметризованные запросы, транзакции, read-only, работа с файлом и :memory: (Справка модуля db →).

Создание

var db = sqlite.open("data.db");
var memory = sqlite.memory();

Модуль использует SQLite amalgamation, собранную вместе с приложением. Для работы не нужен qsqlite.dll.

Параметры

Позиционные параметры передаются массивом, именованные параметры — кортежем. Для именованных параметров ключ указывается вместе с префиксом :, @ или $.

db.exec("insert into people(name, age) values (?, ?)", #["Alice", 30]);
db.exec("insert into people(name, age) values (:name, :age)", #{
    ":name": "Bob",
    ":age": 41
});

Пример

var db = sqlite.open("people.db");
db.exec("create table if not exists people(id integer primary key, name text, age integer)");
db.exec("insert into people(name, age) values (?, ?)", #["Alice", 30]);

var rows = db.query("select id, name, age from people order by id");
for (var row : rows) {
    print(row.id + ": " + row.name + ", " + row.age);
}
db.close();
