QXlsxDocument - Работа с Excel-файлами

Класс qt.XlsxDocument() предоставляет API для чтения/записи XLSX-файлов через Qt. Доступен только в GUI-проектах (qodeqt, qodegui).

Основные методы

МетодОписание
doc.open(filename)Открывает существующий XLSX-файл. Поддерживает форматы: .xlsx, .xls (через конвертацию), .csv
doc.create(filename)Создает новый файл. Если файл существует - перезаписывает
doc.save()Сохраняет в текущий файл
doc.saveAs(filename)Сохраняет в другой файл
doc.saveAsCSV(filename)Экспортирует данные в CSV-файл (без форматирования)

Работа с данными

doc.read(row, col)Чтение ячейки (1-based индексы). Возвращает QVariant
doc.write(row, col, value)Запись значения. Поддерживает: числа, строки, даты, логики
doc.readAll()Возвращает массив массивов (QVariantList) со всеми данными
var doc = qt.XlsxDocument();    // или
var doc = qt.QXlsxDocument();

Возвращает объект QXlsxDocument (через QtAdapter). Доступен только в проектах с GUI (qodeqt, qodegui).

Примеры использования

Базовый пример

var doc = qt.XlsxDocument();
        doc.open("data.xlsx");
        
        // Чтение данных
        var rows = doc.readAll();
        for (var i = 0; i < rows.size(); i++) {
            print(rows[i][0] + " | " + rows[i][1]);
        }
        
        // Запись данных
        doc.write(2, 1, "Новое значение");
        doc.save();

Работа с листами

doc.addSheet("Отчеты");
        doc.selectSheet(1);
        doc.write(1, 1, "Данные из второго листа");
var doc = qt.XlsxDocument();
doc.open("data.xlsx");
print("Строк: " + doc.rowCount());
print("Колонок: " + doc.columnCount());

var rows = doc.readAll();
for (var i = 0; i < rows.size(); i++) {
    var row = rows[i];
    print(row[0] + " | " + row[1] + " | " + row[2]);
}

// Чтение отдельной ячейки
var val = doc.read(1, 1);

// Запись
doc.write(1, 1, "Имя");
doc.write(1, 2, "Возраст");
doc.save();

// Создание нового файла
var newDoc = qt.XlsxDocument();
newDoc.create("new.xlsx");
newDoc.write(1, 1, "Hello");
newDoc.save();

// Листы
doc.addSheet("Лист2");
doc.selectSheet(1);
doc.write(1, 1, "Данные листа 2");
doc.save();

Пайплайн (библиотека xlsxedit.prg)

Для «данные → xlsx → читать обратно» удобно подключать `xlsxedit` (loadModule):

loadModule(file.join(file.dirname(system.getcommandline().args[0]), "xlsxedit.prg"));

var doc = xlsxedit.create("report.xlsx");
xlsxedit.writeMatrix(doc, #[
    #["Товар", "Цена"],
    #["Мышь", 450.5],
    #["Клавиатура", 1250]
]);
doc.setColumnWidth(1, 30);
xlsxedit.save(doc);

var doc2 = xlsxedit.open("report.xlsx");
var all = xlsxedit.readMatrix(doc2);      // массив массивов, 1-based
var row = xlsxedit.findRow(doc2, 1, "Мышь");  // 2
xlsxedit.appendRow(doc2, #["Итого", ""]);

Совместимость и ограничения

  • Поддерживает XLSX (Office 2007+), CSV, XLS (через конвертацию)
  • Максимальное количество строк: 1,048,576
  • Максимальное количество столбцов: 16,384
  • Форматирование ячеек (цвет, шрифт) не сохраняется при чтении/записи

Типы данных

Поддерживаемые типы:

  • Числа (целые, дробные)
  • Строки
  • Даты (формат YYYY-MM-DD)
  • Логические значения (true/false)

Советы по производительности

  • Используйте readAll() только для небольших файлов (<10k строк)
  • Для массовой записи используйте write(row, col, value) в цикле
  • Избегайте частых вызовов save() - лучше использовать saveAs() при необходимости
