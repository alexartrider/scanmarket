ANSI-коды консоли

Для цветного вывода в консоли (print).

КонстантаОписание
colors.ansiResetСброс форматирования
colors.ansiBoldЖирный шрифт
colors.ansiUnderlineПодчёркивание
colors.ansiBlack ... colors.ansiWhiteОсновные цвета текста
colors.ansiBrightBlack ... colors.ansiBrightWhiteЯркие цвета текста
colors.ansiGrayBgСерый фон
colors.ansiGrayFgСерый текст

Пример

print(colors.ansiRed + "Ошибка!" + colors.ansiReset);
print(colors.ansiBold + colors.ansiGreen + "OK" + colors.ansiReset);
