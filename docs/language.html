Автоопределение типа для #{...}: если элементы — пары "key": value, это кортеж; если простые значения — множество. Пустой литерал #{} — это пустое МНОЖЕСТВО; для пустого кортежа используйте #tuple{}.

Коллекции: семантика (важно для библиотек)

  • Передача по значению (COW): кортежи и массивы передаются в функции по значению. Изменения параметра-контейнера внутри функции (…push(), присваивание полю) не видны вызывающему — возвращайте новое значение из функции.
  • Встроенные методы кортежа перекрывают поля: имена size, empty, clone, type, tostring, has, get, set, remove, contains, keys, values, … — это методы; поле кортежа с таким именем в вызове t.name() недоступно. Не называйте полями объектов имена встроенных методов.
  • json.setPath / removePath возвращают новый корень (исходный не меняется).

Классы

class Person {
    var name;
    var age;

    // Конструктор
    Person(name, age) {
        this.name = name;
        this.age = age;
    }

    // Метод
    function greet() {
        return "Я \(this.name), \(this.age) лет";
    }

    // Деструктор
    ~Person() { }
}

// Наследование
class Student : Person {
    var university;

    Student(name, age, university) {
        this::Person(name, age);  // вызов конструктора базового
        this.university = university;
    }
}

var s = Student("Иван", 20, "МГУ");
print(s.greet());          // Я Иван, 20 лет
print(s.university);       // МГУ

Классы и наследование

class Animal {
    Animal(name, sound) {
        this.name = name;
        this.sound = sound;
    }
    function speak() {
        return "\(this.name) говорит \(this.sound)!";
    }
}

class Dog : Animal {
    Dog(name) : Animal(name, "Гав") {   // вызов базового конструктора
        this.tricks = 0;
    }
    function fetch() {
        this.tricks = this.tricks + 1;
        return "\(this.name) приносит палку! (трюк #\(this.tricks))";
    }
}

var rex = Dog("Рекс");
print(rex.speak());       // Рекс говорит Гав!
print(rex.fetch());       // Рекс приносит палку! (трюк #1)

Регулярные выражения

Шаблоны используют ECMAScript std::regex. Строки сопоставляются как UTF-8 байты, не как Unicode-символы; \w, точка и границы символов не учитывают Unicode. Строковые regex-методы могут выбросить исключение для некорректного шаблона.

"12345".regexmatch("\\d+")            // true — вся строка совпадает
"hello 123".regexsearch("\\d+")       // true — частичное совпадение
"hello 123 world".regexreplace("\\d+", "NUM")  // "hello NUM world"
"a,b,,c".regexsplit(",").size()       // 4
"a1 b2 c3".regexfindall("\\d")       // #["1","2","3"]

Unicode

Индексы и позиции методов поиска строк считаются в кодовых единицах UTF-16; code point вне BMP занимает две позиции.

"hello".codepointcount()             // 5 — количество codepoints
"ABC".codepointat(0)                  // 65 — Unicode код символа
"hello".isvalidutf16()               // true
"ABC".tocodepoints()                  // #[65, 66, 67]
