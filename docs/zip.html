Плагин Zip

Работа с ZIP-архивами без внешних программ (нативная реализация на базе miniz)

RUEN

Главная / Плагины / Zip

Особенности

  • Не требует установки 7-Zip и вызова внешних процессов.
  • Поддержка UTF-8 имён файлов (в т.ч. кириллица).
  • Защита от path traversal при извлечении.
  • Пароль (шифрование ZIP) не поддерживается.

Загрузка плагина

loadPlugin("plugins/zip.dll");

Создание объекта

var z = zip();

list(archive)

Возвращает массив кортежей (или null, если архив не открылся).

Поле кортежаТипОписание
pathstringПуть файла внутри архива
sizeintРазмер (несжатый) в байтах
compressedintСжатый размер в байтах
modifiedstringДата модификации (YYYY-MM-DD HH:MM:SS)
crcstringКонтрольная сумма CRC32 (hex)
methodstringМетод сжатия: store, deflate
encryptedint (0/1)Зашифрована ли запись
directoryint (0/1)Является ли запись каталогом
var z = zip();
var files = z.list("archive.zip");
for (var f : files) {
    print(f.path + " — " + f.size + " байт, CRC=" + f.crc + ", " + f.method);
}

extract(archive, destPath, [password], [withPaths])

Извлекает архив в destPath. withPaths=true (по умолчанию) сохраняет структуру каталогов, false — извлекает все файлы «плоско» в корень. Пароль не поддерживается (архивы с шифрованием не извлекаются).

var z = zip();

// С сохранением путей
var ok = z.extract("archive.zip", "C:\\output");

// Без структуры каталогов
z.extract("archive.zip", "C:\\flat", "", false);

extractFile(archive, fileName, destPath, [password])

Извлекает один файл по имени внутри архива.

var z = zip();
var ok = z.extractFile("archive.zip", "docs/readme.txt", "C:\\output");
print(ok);  // 1

create(archive, files, [format], [password], [level])

АргументТипПо умолчаниюОписание
archivestring—Путь к создаваемому архиву
filesArray<string>—Файлы или папки (папки добавляются рекурсивно)
formatstring"zip"Поддерживается только "zip"
passwordstring—Шифрование не поддерживается
levelint5Уровень сжатия 0-9 (0=без сжатия)
var z = zip();

// Простой ZIP из файлов
z.create("backup.zip", #[
    "C:\\Docs\\file1.txt",
    "C:\\Docs\\file2.txt"
]);

// Целая папка — рекурсивно
z.create("data.zip", #["C:\\Data"]);

// Без сжатия
z.create("store.zip", #["file.bin"], "zip", "", 0);

test(archive)

Проверяет целостность архива (распаковка всех записей с проверкой CRC32).

var z = zip();
if (z.test("backup.zip")) {
    print("Архив целый!");
} else {
    print("Архив повреждён!");
}

info(archive)

Возвращает tuple {type, files, size, compressed} или null.

var z = zip();
var info = z.info("archive.zip");
print(info.type);       // "zip"
print(info.files);      // количество записей
print(info.size);       // суммарный несжатый размер

Пример

loadPlugin("plugins/zip.dll");

var z = zip();
z.create("backup.zip", #["C:\\Important"]);

var files = z.list("backup.zip");
print("Файлов в архиве: " + files.size());

if (z.test("backup.zip")) {
    z.extract("backup.zip", "C:\\restore");
    print("Восстановлено успешно");
}
