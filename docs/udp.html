UdpClient — UDP-клиент

Создаёт UDP-сокет для отправки и приёма дейтаграмм. При вызове bind() автоматически запускает фоновый поток приёма.

Создание

var client = UdpClient();

bind(port, [addr])

Привязывает сокет к порту и запускает фоновый поток приёма данных. Если порт=0, ОС выберет свободный порт автоматически.

АргументТипПо умолчаниюОписание
portint—Номер порта (0 = автовыбор)
addrstring"0.0.0.0"Адрес привязки
var c = UdpClient();
c.bind(0);  // Автоматический выбор порта
print(c.port);  // 54321 (пример)

send(host, port, data)

Отправляет UDP-дейтаграмму. Принимает строку или ByteArray.

var c = UdpClient();
c.bind(0);

// Отправка строки
c.send("127.0.0.1", 9000, "Hello!");

// Отправка ByteArray
var data = file.readbytes("photo.jpg");
c.send("192.168.1.100", 8080, data);

recv([maxBytes], [asText], [peek])

Читает одну дейтаграмму из буфера. Если данных нет — возвращает null.

АргументТипПо умолчаниюОписание
maxBytesint65535Макс. размер дейтаграммы
asTextboolfalsetrue — data как строка, false — ByteArray
peekboolfalsetrue — не удалять из буфера

Возвращает кортеж:

ПолеТипОписание
datastring / bytearrayДанные дейтаграммы
ipstringIP-адрес отправителя
portintПорт отправителя
var pkt = c.recv();
if (pkt != null) {
    print("От: " + pkt.ip + ":" + pkt.port);
    print("Данные: " + pkt.data);
}

// Чтение как текст
var pkt2 = c.recv(1024, true);

UdpServer — UDP-сервер

Создаёт UDP-сокет для приёма и отправки дейтаграмм. Автоматически отслеживает пиров.

Создание

var server = UdpServer();

receive([asText], [maxBytes], [peek])

Читает одну дейтаграмму из буфера. Формат аналогичен UdpClient.recv().

АргументТипПо умолчаниюОписание
asTextboolfalsetrue — data как строка
maxBytesint65535Макс. размер
peekboolfalseНе удалять из буфера
var server = UdpServer();
server.bind(9000);

// Ожидание данных
while (true) {
    var pkt = server.receive(true);
    if (pkt != null) {
        print(pkt.ip + ": " + pkt.data);
        server.reply("OK");  // Ответ тому же адресату
    }
    system.sleep(0.01);
}

reply(data)

Отправляет ответ последнему отправителю (из последнего вызова receive()). Удобно для реализации request-reply протоколов.

var pkt = server.receive(true);
if (pkt != null) {
    print("Запрос от " + pkt.ip + ":" + pkt.port);
    server.reply("Получено: " + pkt.data);
}

peers()

Возвращает список всех пиров, с которых когда-либо приходили данные.

var peers = server.peers();
for (var p : peers) {
    print(p.ip + ":" + p.port);
}

Примеры

Базовый обмен дейтаграммами

loadPlugin("udp");

var sender = UdpClient();
sender.bind(0);

var receiver = UdpServer();
receiver.bind(9000);

sender.send("127.0.0.1", 9000, "Привет UDP!");
system.sleep(0.1);

var pkt = receiver.receive(true);
print(pkt.data);  // Привет UDP!
print(pkt.ip);    // 127.0.0.1

sender.close();
receiver.close();

Request-Reply (эхо-сервер)

loadPlugin("udp");

var server = UdpServer();
server.bind(8080);
print("Эхо-сервер запущен на порту 8080");

// Серверный цикл
while (true) {
    var pkt = server.receive(true);
    if (pkt != null) {
        print(pkt.ip + ": " + pkt.data);
        server.reply(pkt.data);  // Эхо
    }
    system.sleep(0.01);
}

Broadcast-рассылка

loadPlugin("udp");

var client = UdpClient();
client.bind(0);

// Рассылка всем в сети
client.broadcast(9000, "Обнаружение сервиса");

Multicast

loadPlugin("udp");

// Подписчик
var sub = UdpClient();
sub.bind(9001);
sub.joingroup("239.0.0.1", "192.168.1.100");

// Издатель
var pub = UdpClient();
pub.bind(0);
pub.send("239.0.0.1", 9001, "Multicast hello!");

Отправка ByteArray (бинарные данные)

loadPlugin("udp");

var client = UdpClient();
client.bind(0);

// Чтение бинарного файла
var data = file.readbytes("firmware.bin");
client.send("192.168.1.50", 5000, data);

// Получение бинарных данных
var server = UdpServer();
server.bind(5001);
var pkt = server.receive();  // asText=false по умолчанию
if (pkt != null) {
    print(typeName(pkt.data));  // "bytearray"
    print(pkt.data.size());
}

Peers — отслеживание адресатов

loadPlugin("udp");

var server = UdpServer();
server.bind(9000);

// Принимаем пакеты
for (var i = 0; i < 10; i++) {
    var pkt = server.receive();
    system.sleep(0.1);
}

// Смотрим кто отправлял
var peers = server.peers();
print("Известные пиры: " + peers.size());
for (var p : peers) {
    print("  " + p.ip + ":" + p.port);
}

Примечания

  • Дейтаграммы. UDP не гарантирует доставку и порядок. Каждый send() — одна дейтаграмма.
  • Буферизация. Данные буферизуются фоновым потоком. receive() / recv() читают из буфера без блокировки.
  • bind(port=0). ОС выберет свободный порт. Узнать номер: client.port / server.port.
  • reply() отправляет последнему отправителю. Если receive() не вызывался — возвращает 0.
  • Multicast. Используйте joingroup() / leavegroup() для управления группами. Адрес группы: 224.0.0.0 — 239.255.255.255.
  • Broadcast. Адрес 255.255.255.255. Может быть заблокирован файрволом.
  • Размер дейтаграммы. Максимум 65535 байт. Рекомендуется ≤ 1472 байт для избежания фрагментации.
  • Очистка. При завершении скрипта все сокеты и потоки освобождаются автоматически.
