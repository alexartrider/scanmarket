Подключение

Библиотеки лежат в qt/scriptlib/ и подключаются через loadModule — только этот способ оставляет функции в Script::Modules (в отличие от execute, который выгружает модуль сразу). Путь удобно считать от каталога исполняемого файла (стабилен для Debug qt/bind и Release qt/bin):

var scriptlib = file.normalize(file.join(file.dirname(system.getcommandline().app), "..", "scriptlib"));
loadModule(file.join(scriptlib, "qtestlib.prg"));
loadModule(file.join(scriptlib, "cli.prg"));
loadModule(file.join(scriptlib, "funcedit.prg"));
loadModule(file.join(scriptlib, "jsonedit.prg"));
loadModule(file.join(scriptlib, "fileedit.prg"));
loadModule(file.join(scriptlib, "xlsxedit.prg"));

Тесты в qt/sample/ подключают библиотеки соседним каталогом: file.join(file.dirname(system.getcommandline().args[0]), "..", "scriptlib", "cli.prg").

Безопасное редактирование файлов (fileedit)

Мгновенные атомарные правки (temp-файл + замена, как file.writeatom) и идемпотентны; opts — те же, что у writeatom: {"enc","overwrite","backup","verify"}. Без opts запись по старым правилам (UTF-8 без BOM). Если менять нечего, мгновенные правки возвращают 0 и не пишут файл (mtime не меняется).

ФункцияОписание
fileedit.replaceAll(path, old, new, [opts])Заменить все вхождения → 1 (было найдено) / 0 (нет)
fileedit.replaceFirst(path, old, new, [opts])Заменить только первое вхождение → 1 / 0
fileedit.edit(path, editFn, [opts])editFn(текст) → новый текст, атомарно
fileedit.filter(path, lineFn, [opts])Построчно: lineFn(строка) → строка или null (удалить)
fileedit.prepend(path, text, [opts])Вставить текст в начало файла
fileedit.append(path, text, [opts])Дописать текст в конец (с переводом строки)
fileedit.replaceAll("app.json", "localhost", "192.168.111.7", #{"backup": 1});
// "отредактировать функцию — одним вызовом, не серией str.replace":
fileedit.edit("tool.prg", function(text) {
    return funcedit.replaceBody(text, "compute", " return a * b; ");
});

Планирование и применение (plan/apply)

Цикл «сначала посмотреть, потом записать» для утилит. plan* читает файл, вычисляет новую версию, число совпадений и diff — и ничего не пишет. apply(plan) перед записью перечитывает файл и сравнивает с содержимым на момент плана: при внешнем изменении — исключение-конфликт без записи. Запись — через file.writeatom с сохранением исходной кодировки (см. ниже).

ФункцияОписание
fileedit.planReplaceAll / planReplaceFirst(path, old, new)План замен (всех / первой)
fileedit.planEdit(path, editFn)План по функции-редактору
fileedit.planFilter(path, lineFn)План построчного фильтра
fileedit.planPrepend / planAppend(path, text)План вставки в начало / конец
fileedit.planContext(path, old, new)Контекстная замена: только при единственном совпадении; при 0 или нескольких — plan.diagnostics и отказ apply
fileedit.apply(plan, [opts])Применить план → 1 (записано) / 0 (нечего менять). opts: {"enc","backup","verify","overwrite","expect"}; expect — ожидаемое число изменений (сверяется с plan.count)

План — обычное значение #{"path","kind","orig","next","count","diff","enc","bom","old","new","diagnostics"}, не зависит от глобального состояния. Повторное применение того же плана не перезаписывает файл молча: после первой правки содержимое стало next ≠ orig → конфликт.

var plan = fileedit.planReplaceAll("cfg.txt", "old", "new");
if (plan.count != 1) throw "ожидалось ровно одно вхождение";
fileedit.apply(plan, #{"backup": 1});
// внешний edit между plan и apply -> fileedit.apply: файл изменился с момента планирования

Сохранение кодировки исходного файла

plan* фиксирует кодировку исходного файла через file.readmeta(path) (поля plan.enc/plan.bom), apply сохраняет её при записи через file.writeatom. Явный opts.enc у apply переопределяет кодировку. Переводы строк LF/CRLF не нормализуются — сохраняются как прочитаны.

Политика неоднозначных случаев (задокументирована):

  • ASCII/UTF-8 без BOM → запись как UTF-8 без BOM (безопасно: ASCII ⊂ UTF-8);
  • BOM-кодировки различаются корректно (UTF-8 BOM, UTF-16 LE/BE);
  • UTF-16 BE не поддержано атомарной записью → ошибка до замены файла;
  • UTF-16 LE без BOM → запись всегда добавит BOM, поэтому правка запрещена;
  • кодировка не распознана (file.ENC_UNKNOWN) → ошибка с требованием передать enc явно.

Обычный file.writeatom без новых параметров продолжает работать по старым правилам (по умолчанию UTF-8 без BOM). Метаданные кодировки доступны и напрямую: file.readmeta(path) → #{"text","enc","bom"} (см. file).

Командная строка утилит (cli)

Разбор аргументов по схеме на основе system.getcommandline().parsed (упорядоченные токены: флаг/значение/позиционный/--). Схема — кортеж с массивом params: #{"name","short","type","default","required","repeat","help"}.

ФункцияОписание
cli.parse(schema, [cmdline])Разбор → #{"opts","args","help"}; ошибки — исключения. cmdline по умолчанию — system.getcommandline()
cli.help(schema)Справка, сгенерированная из той же схемы
loadModule(file.normalize(file.join(file.dirname(system.getcommandline().app), "..", "scriptlib", "cli.prg")));
var schema = #{
    "program": "myutil", "usage": "[опции] FILE", "positional": "FILE — входной файл",
    "params": #[
        #{"name": "output", "short": "o", "type": "string", "default": "out.txt", "help": "файл результата"},
        #{"name": "verbose", "short": "v", "type": "bool", "help": "подробный вывод"},
        #{"name": "count", "type": "int", "help": "сколько раз"},
        #{"name": "mode", "type": "string", "required": 1, "help": "режим"}
    ]
};
var r = cli.parse(schema);       // использует getcommandline().parsed
if (r.help) { print(cli.help(schema)); return 0; }
print("output=" + r.opts.output + " verbose=" + r.opts.verbose + " count=" + r.opts.count);
print("files=" + json.stringify(r.args));

Синтаксис: длинные --name/--name=value, короткие -o (группа -abc — булевы), значение отдельным аргументом --output result.txt / -o result.txt; -- — конец флагов; типы string/int/float/bool с проверкой значений; обязательные и значения по умолчанию; --help/-h (если схема не объявляет свои) дают r.help=1.

Политика повторных параметров (задокументирована, не случайна): по умолчанию последнее значение побеждает (как argparse); у параметра можно задать "repeat": "error" (ошибка на повтор) или "repeat": "first" (игнорировать повторы). ⚠️ В отличие от system.getcommandline().flags (там первое значение из-за tuple/emplace).

Ограничения: короткий флаг со значением — только отдельным аргументом (-o value), форма -o=value не поддержана; булев параметр принимает значение только через --name=value (отдельное значение после флага не потребляется и уходит в позиционные); поле параметра, совпадающее со встроенным методом tuple (size/has/get/set/...), недоступно через opts.имя (ограничение языка).

Правка функций в исходнике (funcedit)

Находит объявления function Имя(...) [export|local] { ... } (в т.ч. в классах), а также тела-выражения function Имя(...) return <exp>; без фигурных скобок; "function" внутри строк и комментариев игнорируется. Изменения делаются только по найденным границам. source — текст исходника.

ФункцияОписание
funcedit.find(source, name)Ровно одна функция → #{"start","bodyStart","bodyClose","end"}, иначе понятное исключение
funcedit.exists(source, name)Есть ли совпадение → 0/1
funcedit.isUnique(source, name)Ровно одно совпадение → 0/1
funcedit.getBody(source, name)Текст тела (между { и }; у return-функций — «return …» до «;»)
funcedit.replaceBody(source, name, newBody)Новый исходник с заменённым телом
funcedit.replace(source, name, newFuncSource)Замена всей функции целиком
funcedit.insertBefore / insertAfter(source, name, snippet)Вставка фрагмента перед function / после закрывающей } (для return-функций — после «;»)
funcedit.balanced(source)Баланс () [] {} с учётом строк/комментариев → 0/1

JSON-формы (jsonedit)

Работает со строкой JSON (обычно содержимое *.json-формы). Возвращает НОВУЮ строку — исходник не меняется.

ФункцияОписание
jsonedit.format(jsonText, [indent])Переформатировать JSON (по умолчанию 4 пробела)
jsonedit.getText(jsonText, path, [def])Значение по пути (пути вида a.b[0].c)
jsonedit.setText(jsonText, path, value, [indent])JSON-строка после изменения по пути
jsonedit.validateForm(jsonText)Проверка структуры RuntimeForm → #{"ok","errors"}
jsonedit.collectEvents(jsonText)Все события формы/виджетов → массив #{"entity","event","handler"}
jsonedit.findWidgetPath(jsonText, name)Путь к виджету (напр. form.widgets[2]) или null
jsonedit.handlerFor(jsonText, entityPath, event)Имя обработчика события

ФункцияОписание

qt_check(desc, actual, expected)Сравнение через ==
qt_checkJson(desc, actual, expected)Сравнение через json.stringify

qt_ok(desc, cond) / qt_fail(desc, [msg])Булева проверка / безусловный FAIL
qt_throws(desc, fn, [pattern])Функция должна выбросить исключение (по подстроке)
qt_tempdir([prefix])Уникальная временная директория (все файловые тесты работают только там)
qt_quoteArg(a) / qt_run(prog, args, [timeout])Экранирование аргумента / запуск с захватом вывода
qt_done()Итог по всему прогону → 0/1 (в конце теста: return qt_done();)

Тест — обычный скрипт, который в конце делает return rc; (код возврата процесса = 0/1). Запуск всех тестов одним вызовом:

qt\bind\qodeqt.exe qt\sample\run_tests.prg                              // все test_*.prg
qt\bind\qodeqt.exe qt\sample\run_tests.prg test_json*.prg               // по шаблону
qt\bind\qodeqt.exe qt\sample\run_tests.prg --timeout=30000 test_fileedit.prg

Правила устойчивого цикла (проверено эмпирически)

  • Код возврата: заканчивайте программу return 0; (или return rc;) — «return N;» даёт код N. Синтаксическая ошибка файла возвращает код 1, необработанное исключение при выполнении — код 2 (раньше эти сбои маскировались кодом 0). Без явного return код — AsInt() последнего выражения.
  • Вывод: print пишется в консольное окно и в лог qt/bin/log/log_DDMMYYYY.log (параллельно), но НЕ в перенаправляемый OS-stdout — захват stdout дочернего процесса даёт пусто. Результат дочернего запуска проверяйте через файл-маркер + res.code, а не res.stdout.
  • Место журнала: настраивается из скрипта через Log.localFilePath (и Log.remoteFilePath); каталог, если его нет, создаётся рекурсивно автоматически (прежний дефолтный путь qt/bin/log тоже создаётся как раньше). Префикс имени файла — Log.filePrefix.
  • Запуск без shell (пути с пробелами/Unicode безопасны): system.execArgv(#[exe, arg1, arg2], #{"cwd","timeout","outfile"}).
  • Headless: формы и таблицы создаются без GUI — file.setenv("QT_QPA_PLATFORM","offscreen") ДО execArgv.
  • Мутации контейнеров в функциях-параметрах не видны вызывающему (COW) — помощники должны возвращать новое значение.
