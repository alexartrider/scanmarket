Загрузка плагина

Плагин работает только в Windows (Win32 GDI). Захват выполняется в интерактивной пользовательской сессии.

var ok = loadPlugin(file.apppath() + "/plugins/screen.dll");
if (!ok) throw "Не удалось загрузить плагин screen";

Информация об экранах

ФункцияАргументыВозвращаетОписание
ScreenCount()—intКоличество мониторов
ScreenWidth()—intШирина основного монитора, px
ScreenHeight()—intВысота основного монитора, px
ScreenVirtualRect()—TupleГраницы виртуального рабочего стола, см. ниже
ScreenMonitors()—Array<Tuple>Список всех мониторов, см. ниже

ScreenVirtualRect() возвращает кортеж {left, top, width, height} — область, покрывающая все мониторы. Начало координат виртуального экрана — левый верхний угол основного монитора, поэтому при мониторе слева/сверху координаты left/top отрицательные.

ScreenMonitors() возвращает массив кортежей:

ПолеТипОписание
left, topintПозиция монитора в координатах виртуального экрана
width, heightintРазрешение монитора, px
primaryint (0/1)1 — основной монитор

Захват экрана

Результат захвата — полный файл BMP (32 бита на пиксель) в виде ByteArray. Его можно сразу сохранить на диск через file.writebytes, передать в буфер обмена плагином clipboard (ClipboardSetImage) или обработать байтовыми функциями.

ФункцияАргументыВозвращаетОписание
ScreenCapture([cursor])cursor: 0/1 (по умолч. 0)ByteArray (BMP) | nullСнимок основного монитора целиком
ScreenCaptureRect(x, y, w, h, [cursor])x, y, w, h, cursor: 0/1ByteArray (BMP) | nullСнимок прямоугольной области виртуального экрана

Особенности:

  • Координаты ScreenCaptureRect задаются в системе координат виртуального экрана (см. ScreenVirtualRect).
  • Части области за пределами экранов заполняются чёрным.
  • При cursor = 1 на снимок добавляется системный курсор (в точке его фактического положения).

Примеры

Скриншот всего экрана с курсором

var shot = ScreenCapture(1);           // с курсором
if (!shot.isnull())
    file.writebytes(file.apppath() + "/screen.bmp", shot);

Снимок области и передача в буфер обмена

var img = ScreenCaptureRect(0, 0, 640, 480);
if (!img.isnull()) {
    loadPlugin(file.apppath() + "/plugins/clipboard.dll");
    ClipboardSetImage(img);            // теперь можно вставить в любой редактор
}

Скриншот всех мониторов

var v = ScreenVirtualRect();
var all = ScreenCaptureRect(v.left, v.top, v.width, v.height);  // весь виртуальный рабочий стол
file.writebytes("all_monitors.bmp", all);

// Или по одному монитору:
for (var m : ScreenMonitors())
    file.writebytes("monitor_" + m.left + "_" + m.top + ".bmp",
                    ScreenCaptureRect(m.left, m.top, m.width, m.height));
