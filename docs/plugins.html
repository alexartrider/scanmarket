Подключение плагинов

Плагины загружаются через глобальную функцию loadPlugin:

// Загрузка плагина по имени файла (без расширения .dll/.so)
loadPlugin("archive7zip");

// С псевдонимом
loadPlugin("archive7zip", "zip");

Возвращает true при успешной загрузке, false — если не найден.

Примечание: ключевое слово uses используется только для встроенных модулей (str, math, file, datetime и др.).

Безопасность арены (ScriptValueArena)

ScriptValueArena — это система управления временем жизни для быстрых значений скрипта. Значения, выделенные через MakeTempValue, живут только на текущем уровне арены. При вызове ArenaLevelScope создаётся новый уровень; при выходе из scopes уровень уничтожается вместе со всеми выделенными на нём значениями.

Правило безопасности

Никогда не возвращайте указатели/ссылки на значения, выделенные внутри ArenaLevelScope.

Если вы создали значение через MakeTempValue внутри scope, вы обязаны либо:

  • Скопировать значение (Clone) до завершения scope
  • Или перенести значение на кучу через ScriptValue (shared_ptr)

Пример ошибки

// НЕПРАВИЛЬНО — значение уничтожается при выходе из scope
QScriptValueHandle HostObjectGet(QScriptContextHandle ctx, QScriptValueHandle obj)
{
    ArenaLevelScope scope{ctx->arena};
    QScriptValueHandle val = MakeTempValue(ctx, ScriptValue(int64_t(42)));
    return val; // val указывает на уничтоженную память!
}

// ПРАВИЛЬНО — копируем значение до завершения scope
QScriptValueHandle HostObjectGet(QScriptContextHandle ctx, QScriptValueHandle obj)
{
    ArenaLevelScope scope{ctx->arena};
    QScriptValueHandle val = MakeTempValue(ctx, ScriptValue(int64_t(42)));
    return val->Clone(); // возвращаем копию на постоянном хранилище
}

Где это критично

Эта проблема затрагивает функции обратного вызова плагинов: HostObjectGetProperty, HostObjectCallMethod, HostObjectGetPropertyNames, HostObjectCall. Уровень арены уже управляется вызывающим кодом (PluginFuncWrapper, ExternalObjectWrapper::CallMethod); создавать вложенные ArenaLevelScope в этих функциях нельзя.

Симптомы

При нарушении этого правила возникает ошибка FATAL: corrupted variant — память, выделенная на арене, перезаписывается другими значениями после уничтожения уровня, и скриптовый движок пытается прочитать невалидные данные.
