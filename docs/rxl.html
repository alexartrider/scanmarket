Таблица QRXLWidget (rxl)

Мини-Excel-виджет форм: загрузка из JSON, чтение/запись ячеек из скрипта, экспорт в XLSX/PDF/PNG

RUEN

Главная / QT / RXL таблица

Где взять объект таблицы

СпособПример
Виджет формы (рекомендуется)В JSON-форме укажите виджет {"class":"QRXLWidget","name":"table1"}, затем var grid = form.findWidget("table1");
Отдельное окноvar w = dialog.newtable(owner, [title]); — окно RXLMainWindow (GUI)

Координаты ячеек в методах — 0-based (в отличие от Excel): строка 1 = индекс 0.

Загрузка данных (JSON)

grid.fromMemory(jsonText, tableName) — ищет в документе раздел "rxl" таблицу с указанным именем и заполняет ячейки. Формат ячеек: cells[строка][столбец], каждая ячейка — {"t": текст, "uc": объединение_по_колонкам, "ur": объединение_по_строкам}; пустая ячейка — {}. У мастера объединения uc/ur > 0, у подчинённых — отрицательные смещения к мастеру.

loadModule(file.normalize(file.join(file.dirname(system.getcommandline().app), "..", "scriptlib", "qtestlib.prg")));

var rxlDoc = json.stringify(#{
    "form": #{},
    "rxl": #[
        #{
            "name": "Прайс",
            "info": #{"maxCol": 2, "maxRow": 3, "viewGrid": 1},
            "data": #{
                "cells": #[
                    #[ #{"t": "Товар"}, #{"t": "Цена"}, #{"t": "Наличие"} ],
                    #[ #{"t": "Мышь"}, #{"t": "450.5"}, #{"t": "да"} ],
                    #[ #{"t": "Клавиатура"}, #{"t": "1250"}, #{"t": "нет"} ],
                    #[ #{"t": "Итого по прайсу", "uc": 2, "ur": 0},
                       #{"t": "", "uc": -1, "ur": 0}, #{"t": "", "uc": -2, "ur": 0} ]
                ]
            }
        }
    ]
});
grid.fromMemory(rxlDoc, "Прайс");

Методы (из скрипта)

МетодОписание
grid.fromMemory(jsonText, tableName) / fromFile(path, tableName)Заполнить таблицу из JSON (0/1)
grid.setRow(r) / setCol(c)Текущая ячейка, 0-based
grid.getText() / setText(s)Чтение/запись текста текущей ячейки
grid.getLastRow() / getLastCol()Последняя заполненная строка/столбец
grid.getMaxRow() / getMaxCol()Максимальные пределы
grid.tableName() / setTableName(n)Имя таблицы
grid.mergeSelection() / unMergeSelection()Объединение/разъединение выделенного (выделение — через setSelection)
grid.insertRow() / insertCol() / deleteRows() / deleteCols()Структурные операции
grid.exportExcel(path)Экспорт в XLSX (числа из текста преобразуются автоматически; объединения сохраняются)
grid.exportPDF(path)Экспорт в векторный PDF (страницы A4, колонтитулы, разрывы — как в предпросмотре)
grid.exportFile(path)Растровые PNG/JPG/BMP/GIF (при нескольких страницах — имя_1.png…)
grid.setRow(1); grid.setCol(2);
print(grid.getText());             // "450.5"
grid.setRow(3); grid.setCol(0);
grid.setText("Монитор 4K");

grid.exportExcel(file.join(dir, "прайс.xlsx"));
grid.exportPDF(file.join(dir, "прайс.pdf"));

Экспорт можно проверять обратным чтением: XLSX открывается через qt.XlsxDocument() / xlsxedit.open().

Headless-работа

Всё перечисленное работает без GUI-сессии: развёрнут платформенный плагин offscreen, запускайте с QT_QPA_PLATFORM=offscreen (см. QT интеграция) и проверяйте реальную платформу через qt.platformName().
