Плагин Clipboard (буфер обмена)

Чтение и запись текста и изображений в системный буфер обмена Windows

RUEN

Главная / Плагины / Clipboard

Загрузка плагина

Плагин использует системный буфер обмена Windows (Win32). Работает в qodeqt, qodegui и qodedesigner.

var ok = loadPlugin(file.apppath() + "/plugins/clipboard.dll");
if (!ok) throw "Не удалось загрузить плагин clipboard";

Изображения

Обмен изображениями происходит через ByteArray. Плагин работает с DIB (Device-Independent Bitmap):

  • ClipboardGetImage() возвращает полный файл BMP (с заголовком "BM") — его можно сразу сохранить на диск через file.writebytes;
  • ClipboardSetImage(data) принимает полный BMP-файл или «голый» DIB (данные без заголовка файла).

Чтение из буфера выполняется из форматов CF_DIB / CF_DIBV5 — это стандартные форматы, в которые Windows и большинство приложений (Print Screen, браузеры, графические редакторы) помещают изображения.

Примеры

Копирование и вставка текста

var oldText = ClipboardGetText();      // что было в буфере
ClipboardSetText("Привет, мир!");
if (ClipboardHasText()) {
    print("В буфере: " + ClipboardGetText());
}

Сохранение изображения из буфера в файл

if (ClipboardHasImage()) {
    var info = ClipboardGetImageInfo();
    print(info.width + "x" + info.height + ", " + info.bpp + " bpp");

    var img = ClipboardGetImage();        // полный BMP-файл
    file.writebytes(file.apppath() + "/clipboard.bmp", img);
    print("Сохранено " + img.size() + " байт");
}

Помещение изображения из файла в буфер

var data = file.readbytes("picture.bmp");   // ByteArray с полным BMP-файлом
ClipboardSetImage(data);
print("hasImage: " + ClipboardHasImage());

Перенос изображения между приложениями

if (ClipboardHasImage()) {
    ClipboardSetText("Скриншот был скопирован из буфера");
}
