UdpClient — UDP client

Creates a UDP socket for sending and receiving datagrams. Calling bind() automatically starts a background receive thread.

Creation

var client = UdpClient();

bind(port, [addr])

Binds the socket to a port and starts a background data receive thread. If port=0, the OS picks a free port automatically.

ArgumentTypeDefaultDescription
portint—Port number (0 = automatic selection)
addrstring"0.0.0.0"Bind address
var c = UdpClient();
c.bind(0);  // Automatic port selection
print(c.port);  // 54321 (example)

send(host, port, data)

Sends a UDP datagram. Accepts a string or a ByteArray.

var c = UdpClient();
c.bind(0);

// Sending a string
c.send("127.0.0.1", 9000, "Hello!");

// Sending a ByteArray
var data = file.readbytes("photo.jpg");
c.send("192.168.1.100", 8080, data);

recv([maxBytes], [asText], [peek])

Reads one datagram from the buffer. If there is no data — returns null.

ArgumentTypeDefaultDescription
maxBytesint65535Max datagram size
asTextboolfalsetrue — data as a string, false — ByteArray
peekboolfalsetrue — do not remove from the buffer

Returns a tuple:

FieldTypeDescription
datastring / bytearrayDatagram payload
ipstringSender's IP address
portintSender's port
var pkt = c.recv();
if (pkt != null) {
    print("From: " + pkt.ip + ":" + pkt.port);
    print("Data: " + pkt.data);
}

// Reading as text
var pkt2 = c.recv(1024, true);

UdpServer — UDP server

Creates a UDP socket for receiving and sending datagrams. Tracks peers automatically.

Creation

var server = UdpServer();

Server properties

receive([asText], [maxBytes], [peek])

Reads one datagram from the buffer. The format matches UdpClient.recv().

ArgumentTypeDefaultDescription
asTextboolfalsetrue — data as a string
maxBytesint65535Max size
peekboolfalseDo not remove from the buffer
var server = UdpServer();
server.bind(9000);

// Waiting for data
while (true) {
    var pkt = server.receive(true);
    if (pkt != null) {
        print(pkt.ip + ": " + pkt.data);
        server.reply("OK");  // Reply to the same sender
    }
    system.sleep(0.01);
}

reply(data)

Sends a reply to the last sender (from the most recent receive() call). Handy for implementing request-reply protocols.

var pkt = server.receive(true);
if (pkt != null) {
    print("Request from " + pkt.ip + ":" + pkt.port);
    server.reply("Received: " + pkt.data);
}

peers()

Returns the list of all peers that data has ever arrived from.

var peers = server.peers();
for (var p : peers) {
    print(p.ip + ":" + p.port);
}

Examples

Basic datagram exchange

loadPlugin("udp");

var sender = UdpClient();
sender.bind(0);

var receiver = UdpServer();
receiver.bind(9000);

sender.send("127.0.0.1", 9000, "Hello UDP!");
system.sleep(0.1);

var pkt = receiver.receive(true);
print(pkt.data);  // Hello UDP!
print(pkt.ip);    // 127.0.0.1

sender.close();
receiver.close();

Request-Reply (echo server)

loadPlugin("udp");

var server = UdpServer();
server.bind(8080);
print("Echo server started on port 8080");

// Server loop
while (true) {
    var pkt = server.receive(true);
    if (pkt != null) {
        print(pkt.ip + ": " + pkt.data);
        server.reply(pkt.data);  // Echo
    }
    system.sleep(0.01);
}

Broadcast

loadPlugin("udp");

var client = UdpClient();
client.bind(0);

// Send to everyone on the network
client.broadcast(9000, "Service discovery");

Multicast

loadPlugin("udp");

// Subscriber
var sub = UdpClient();
sub.bind(9001);
sub.joingroup("239.0.0.1", "192.168.1.100");

// Publisher
var pub = UdpClient();
pub.bind(0);
pub.send("239.0.0.1", 9001, "Multicast hello!");

Sending a ByteArray (binary data)

loadPlugin("udp");

var client = UdpClient();
client.bind(0);

// Reading a binary file
var data = file.readbytes("firmware.bin");
client.send("192.168.1.50", 5000, data);

// Receiving binary data
var server = UdpServer();
server.bind(5001);
var pkt = server.receive();  // asText=false by default
if (pkt != null) {
    print(typeName(pkt.data));  // "bytearray"
    print(pkt.data.size());
}

Peers — tracking senders

loadPlugin("udp");

var server = UdpServer();
server.bind(9000);

// Receive packets
for (var i = 0; i < 10; i++) {
    var pkt = server.receive();
    system.sleep(0.1);
}

// Check who sent data
var peers = server.peers();
print("Known peers: " + peers.size());
for (var p : peers) {
    print("  " + p.ip + ":" + p.port);
}

Notes

  • Datagrams. UDP does not guarantee delivery or ordering. Each send() is one datagram.
  • Buffering. Data is buffered by a background thread. receive() / recv() read from the buffer without blocking.
  • bind(port=0). The OS picks a free port. To get the number: client.port / server.port.
  • reply() sends to the last sender. If receive() was never called — returns 0.
  • Multicast. Use joingroup() / leavegroup() to manage groups. Group address: 224.0.0.0 — 239.255.255.255.
  • Broadcast. Address 255.255.255.255. May be blocked by a firewall.
  • Datagram size. Maximum 65535 bytes. ≤ 1472 bytes is recommended to avoid fragmentation.
  • Cleanup. When the script finishes, all sockets and threads are released automatically.
