Stack (LIFO)

Creation: the Stack() constructor or the #stack{} literal

var s = Stack();
s.push(10);
s.push(20);
s.push(30);
print(s.top());    // 30
print(s.pop());    // 30
print(s.peek());   // 20
print(s.size());   // 2
Property/MethodDescription
s.size()Number of elements
s.empty()true if empty
s[i]Indexed access (0 = top)
s.push(val)Push onto the top
s.top()Return the top element without removing it
s.peek()Alias of top()
s.pop()Remove and return the top element
s.clear()Clear
s.resize(n)Resize (add/remove elements)
s.reserve(n)Reserve memory

Queue (FIFO)

Creation: the Queue() constructor or the #queue{} literal

var q = Queue();
q.push(10);
q.push(20);
q.push(30);
print(q.front());  // 10
print(q.pop());    // 10
print(q.back());   // 30
MethodDescription
q.push(val)Push to the back
q.push_front(val)Push to the front
q.pop()Remove the first element
q.pop_back()Remove the last element
q.front()First element
q.back()Last element
q[i]Indexed access
q.size()Number of elements
q.empty()true if empty
q.resize(n)Resize the queue

PriorityQueue (max-heap)

Creation: the PriorityQueue() constructor or the #priorityqueue{} literal

The larger the priority number, the higher the priority (pop extracts the maximum).

var pq = PriorityQueue();
pq.push("low", 1);
pq.push("high", 10);
pq.push("medium", 5);
print(pq.peek());  // "high"
print(pq.pop());   // "high" (priority 10)
print(pq.pop());   // "medium" (priority 5)
MethodDescription
pq.push(val, priority)Push with a priority (default 0)
pq.pop()Extract the highest-priority element
pq.peek()Look at the top element without removing it
pq.size()Number of elements
pq.empty()true if empty
pq.clear()Clear

Dictionary (case-sensitive)

Creation: the Dictionary() constructor or the #dictionary{} literal

var d = Dictionary();
d.set("name", "Ivan");
d.set("age", 25);
print(d.get("name"));    // "Ivan"
print(d.has("age"));     // true
print(d.size());           // 2

// Dot access
print(d.name);            // "Ivan"

// Key check
print(d.contains("name"));  // true
MethodDescription
d.size()Number of pairs
d.empty()true if empty
d.set(key, val)Set a value
d.get(key)Get a value
d.getdefault(key, def)Get with a default value
d.has(key)Key presence
d.contains(key)Alias of has()
d.remove(key)Remove
d.pop(key)Remove and return
d.keys()Array of keys
d.values()Array of values
d.items()Array of [key, value] tuples
d.update(other)Update from another dictionary
d.clear()Clear

DictionaryCI (case-insensitive)

Creation: the DictionaryCI() constructor or the #dictionaryci{} literal

An analog of Dictionary, but keys are case-insensitive.

var d = DictionaryCI();
d.set("Name", "Ivan");
print(d.get("name"));  // "Ivan" — case does not matter

StringSet

A set of unique strings (case-sensitive). Storage and lookup respect case.

Creation: the StringSet() constructor or with a list of values StringSet("a", "b")

var set = StringSet();
set.add("apple");
set.add("Apple");  // a different element (case matters)
print(set.size());        // 2
print(set.has("apple")); // true
print(set.has("APPLE")); // false
MethodDescription
set.size()Number of elements
set.empty()true if empty
set.add(val)Add (true if added, false if already present)
set.insert(val...)Add multiple values
set.remove(val)Remove (true if present)
set.discard(val)Remove (alias of remove)
set.has(val)Element presence
set.contains(val)Alias of has()
set.toList()Array of all elements
set.values()Alias of toList()
set.pop()Remove and return an arbitrary element
set.update(other)Union with another set
set.clear()Clear

StringSetCI (case-insensitive)

A set of unique strings without case sensitivity. "Name", "NAME" and "name" are one element.

Creation: the StringSetCI() constructor or with a list of values StringSetCI("a", "b")

var set = StringSetCI();
set.add("apple");
set.add("APPLE");  // the same element (case does not matter)
print(set.size());        // 1
print(set.has("Apple")); // true

API is the same as StringSet.

Mutex

var m = Mutex();
m.lock();
// critical section
m.unlock();
Property/MethodDescription
m.lockedtrue if locked
m.lock()Lock
m.tryLock()Try to lock (true/false)
m.unlock()Unlock

LockGuard (RAII)

Automatic unlock when leaving the scope.

var m = Mutex();
{
    var guard = LockGuard(m);
    // critical section
    guard.dismiss();  // optional: release early
}  // automatic unlock

synchronized()

var m = Mutex();
synchronized(m, function() {
    // atomic block
    sharedData += 1;
});
