Reading

FunctionDescription
file.read(path, [enc])Reads as a string (encoding auto-detected by default; the BOM is skipped when present)
file.readlines(path)Array of lines: splits by \n and strips a trailing \r from each line (CRLF reads correctly). Empty lines are kept; a trailing newline does NOT produce an empty tail element (like Python str.splitlines()); an empty file → []. ⚠️ str.split(text, "\n") (regex) returns a trailing empty string for a trailing newline — use readlines for line-by-line work
file.readmeta(path)Reads the file and returns a tuple #{"text", "enc", "bom"}: text + detected encoding (file.ENC_*) + BOM presence. Empty/missing file → enc=UTF8_NO_BOM, text=""; unrecognized encoding (ENC_UNKNOWN) → text="" (content is available via file.readbytes)
file.readbytes(path)Array of int64 values (each element is a byte)

Encoding auto-detection (shared by read and readmeta): BOM (UTF-8/UTF-16 LE/BE) → by BOM; otherwise valid UTF-8 → UTF8_NO_BOM (including plain ASCII — safe, ASCII ⊂ UTF-8); otherwise CP1251-like → CP1251; otherwise UNKNOWN. UTF-16 LE without a BOM is detected by null bytes. The BOM is skipped on read only if it is actually present (BOM-less UTF-16 is decoded without an offset).

Writing

file.write() and file.append() write UTF-16 LE by default (kept for compatibility). For sources and configs use file.writeatom() — UTF-8 without BOM by default.

FunctionDescription
file.write(path, text, [enc])Write a string (UTF-16 LE by default)
file.writebytes(path, data)Write a byte array or ByteArray
file.append(path, text, [enc])Append to the end of the file
file.writeatom(path, text, [opts])Atomic write: temp file + replace. UTF-8 without BOM by default. → true, throws an exception on error
file.writeLines(path, arr, [opts])Atomic write of a string array (join + trailing \n). Analogue of a Python line-writing loop
file.appendLines(path, arr, [opts])Atomic append of a string array to the end of the file

file.writeatom options

file.writeatom(path, text, #{
    "enc":       "utf8" | "utf8-nobom" | "utf16" | "cp1251",  // default utf8-nobom
    "overwrite": 1 | 0,          // 0 — throw an exception if the file already exists
    "backup":    1 | "path.bak", // create a backup before replacing (no backup by default)
    "verify":    1 | 0           // read the file after replacement and check the content (default 1)
});

On a verification error the file is rolled back from the backup if one was enabled.
