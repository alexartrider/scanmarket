Types and Introspection

FunctionDescription
type(val)Numeric type code: 0=null, 1=int, 2=double, 3=string, 4=object, 5=array, 6=tuple, 7=set
typeName(val)Type name as a string (lowercase): "null", "int", "string", "array"...
size(val)Size (string length, number of elements in a collection)
empty(val)true if empty
propertyNames(obj)Property names of an object
exists(name)Whether a variable exists
propertyExists(obj, name)Whether an object property exists
methodExists(obj, name)Whether an object method exists
hash(val)Hash value
type(42)              // 1 (int)
type("hello")        // 3 (string)
type(#[1,2])         // 5 (array)
typeName(42)         // "int"
typeName("hello")    // "string"

// Type check via type():
if (type(val) == 3) print("it is a string");
if (type(val) == 0) print("it is null");

Note: Global functions isnull(), isstring(), isint(), etc. do not exist. Use type(val) or the .isnull() method for objects.

Working with Collections

FunctionDescription
toarray(val)Convert to an array
push(arr, val)Append an element
pop(arr)Remove the last element
clear(arr)Clear a collection
sorted(set)Sort (returns a set)
reversed(arr)Reverse (returns an array)
range(start, [end], [step])Generate a numeric range (returns a set)
foreach(arr, func)Call a function for each element
map(arr, func)Transform each element
filter(arr, func)Filter by a condition
reduce(arr, func, init)Reduce (accumulator)
var arr = #[30, 10, 20];
sorted(arr);        // set: {10, 20, 30}  — NOT an array!
reversed(arr);      // array: [20, 10, 30]

range(5);           // set: {0, 1, 2, 3, 4}
range(2, 5);        // set: {2, 3, 4}

var doubled = map(arr, function(x) { return x * 2; });
var evens = filter(arr, function(x) { return x % 2 == 0; });
var total = reduce(arr, function(acc, x) { return acc + x; }, 0);

String Formatting

Uses printf style (not {0}!):

SpecifierDescription
%sString
%dInteger
%fFloating point
%eExponential
%gShorter of %f/%e
%xHex
%oOctal
%cCharacter
%%Literal %
print(format("Hello %s, value: %d", "World", 42));
// "Hello World, value: 42"

print(format("Pi = %.2f", 3.14159));
// "Pi = 3.14"

JSON (module json)

Detailed reference: Module json

FunctionDescription
json.parse(string)Parse a JSON string → tuple (object) or array
json.stringify(value, [pretty])Value → JSON string
json.stringify(value, true, [indent])Pretty-printed output with indentation (4 spaces by default)
json.validate(string)Validate JSON → true / false
var data = json.parse('{"name": "John", "age": 30}');
print(data.name);  // John

var str = json.stringify(data, true);
print(str);  // pretty-printed with indentation

print(json.validate('{"a":1}'));  // true
