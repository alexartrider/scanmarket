Excel (XLSX) Plugin

Reading and writing XLSX files — the XlsxDocument object model (native implementation based on OpenXLSX)

RUEN

Home / Plugins / Excel

Features

  • Native implementation (C++, OpenXLSX 0.5.1) — no dependency on Qt or external programs.
  • UTF-8 file names and Russian text in cells are supported.
  • Reading and writing: strings, integers and floating-point numbers, booleans, dates, empty cells.
  • Working with sheets, cell merging, widths/heights, hiding rows/columns, document properties.
  • Read/write only .xlsx (.xls and .csv formats are not supported).

Loading the plugin

loadPlugin(file.apppath() + "/plugins/excel.dll");

Creating the object

var doc = XlsxDocument();

Cell data

MethodArgumentsReturnsDescription

readRowrowArrayA row of data

rowCount—intNumber of the last filled row

Row and column indices are 1-based (as in Excel).

doc.write(1, 1, "Name");
doc.write(2, 1, "John");
doc.write(2, 2, 25);
print(doc.read(2, 2));  // 25

Document properties

MethodArgumentsReturnsDescription
documentPropertynamestringProperty value (empty string if not set)
setDocumentPropertyname, valueint (0/1)Set a property
documentPropertyNames—Array<string>List of supported property names (21)

Supported names: Title, Subject, Creator, Author (alias), Keywords, Description, LastModifiedBy, LastPrinted, CreationDate, ModificationDate, Category, Application, DocSecurity, ScaleCrop, Manager, Company, LinksUpToDate, SharedDoc, HyperlinkBase, HyperlinksChanged, AppVersion.

doc.setDocumentProperty("Author", "Tester");
doc.setDocumentProperty("Title", "Monthly report");
print(doc.documentProperty("Title"));

Full example

loadPlugin(file.apppath() + "/plugins/excel.dll");

var doc = XlsxDocument();
doc.create("test_output.xlsx");

var data = #[
    #["Name", "Age", "City"],
    #["John", 25, "Moscow"],
    #["Mary", 28, "Kazan"]
];
for (var i = 0; i < data.size(); i++)
    for (var j = 0; j < data[i].size(); j++)
        doc.write(i + 1, j + 1, data[i][j]);

doc.setColumnWidth(1, 25);
doc.setRowHeight(1, 20);
doc.mergeCells(5, 1, 5, 3);
doc.write(5, 1, "Total");
doc.setDocumentProperty("Author", "Script");
doc.save();
