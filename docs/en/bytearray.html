Creation

var ba = ByteArray();           // new empty instance
var ba = ByteArray.fromString("Hello", ByteArray.encode_utf8);
var ba = ByteArray.fromHex("48656C6C6F");
var ba = ByteArray.fromBase64("SGVsbG8=");

Properties

PropertyDescription
ba.sizeSize in bytes
ba.lengthAlias of size
ba.emptytrue if empty
ba[i]Index access (read/write)

for (var byte : ba) iterates bytes in order as integers 0-255. To get both the index and byte, put the variables in square brackets:

for (var [index, byte] : ba) {
    print(index);
    print(byte);
}

ByteArray is iterated as a sequence, not by its properties like ordinary objects.

Examples

var ba = ByteArray();
ba.push(72, 101, 108, 108, 111);
print(ba.toString());           // "Hello"
print(ba.size());               // 5

var ba2 = ByteArray.fromString("Hello", ByteArray.encode_utf8);
print(ba2.size());              // 5 (UTF-8)
print(ba2.hex());               // hex representation
print(ba2.crc32());             // checksum

var ba3 = ByteArray.fromHex("48656C6C6F");
print(ba3.toString(ByteArray.encode_utf8));  // "Hello"
print(ba3[0]);                  // 72 (code of 'H')
