Formatting

FunctionDescription
datetime.strftime(dt, fmt)Date → string by format
datetime.strptime(str, fmt)String → date by format; Python-compatible parse variant
datetime.datetostring(dt)Date as a string
datetime.timetostring(dt)Time as a string
datetime.datetimetostring(dt)Date+time as a string
var a = datetime.parse("2024-01-15");                      // automatic detection
var b = datetime.parse("15.01.2024", "%d.%m.%Y");       // strict format parsing
var c = datetime.strptime("2024-01-15", "%Y-%m-%d"); // same formatted parsing

When a format is supplied, the entire input must match; a mismatch or invalid date raises an exception. Parsing uses std::get_time format directives, whose supported set may vary between C++ standard libraries.

Examples

var now = datetime.now();
print(datetime.datetimetostring(now));

var d = datetime.makedatetime(2024, 12, 25, 10, 30);
print(datetime.strftime(d, "%d.%m.%Y %H:%M"));  // 25.12.2024 10:30

var future = datetime.addday(now, 30);
print(datetime.daysdiff(now, future));  // 30
