connect(host, [port], [useSSL])

Connects to an SMTP server. Performs the TCP connection, an optional SSL handshake and the greeting (EHLO/HELO).

ArgumentTypeDefaultDescription
hoststring—Server address (domain or IP)
portint465Server port
useSSLbooltrueSSL/TLS connection. If port=465 — defaults to true
// SSL (port 465)
smtp.connect("smtp.mail.ru", 465, true);

// STARTTLS (port 587)
smtp.connect("smtp.gmail.com", 587, false);
smtp.starttls();

starttls()

Switches the connection to TLS after the initial connection. Use it when port=587 and useSSL=false.

smtp.connect("smtp.gmail.com", 587, false);
smtp.starttls();  // TLS handshake
smtp.login("user@gmail.com", "password");

login(user, pass)

Authentication on the server. Tries AUTH PLAIN, then AUTH LOGIN.

smtp.login("user@mail.ru", "password");

send(from, to, subject, body, [isHtml])

Sends a MIME message with UTF-8 encoding.

ArgumentTypeDescription
fromstringSender address
tostringRecipient address
subjectstringMessage subject
bodystringMessage body
isHtmlboolHTML body format (defaults to false)
// Plain message
smtp.send("from@mail.ru", "to@yandex.ru", "Subject", "Message body");

// HTML message
smtp.send("from@mail.ru", "to@yandex.ru", "HTML",
    "<h1>Hello!</h1><p>This is an <b>HTML</b> message</p>", true);

attach(filename, data, [contentType], [contentId])

Adds an attachment to the next message. Call attach() before send().

ArgumentTypeDefaultDescription
filenamestring—File name to display
datastring / ByteArray—Path to a file or a ByteArray
contentTypestring"application/octet-stream"MIME type
contentIdstring—Content-ID for inline attachments
// Attachment from a file
smtp.attach("report.pdf", "C:\\docs\\report.pdf", "application/pdf");

// Attachment from a ByteArray
var data = file.readbytes("image.png");
smtp.attach("image.png", data, "image/png");

// Inline attachment (for HTML)
smtp.attach("logo.png", "logo.png", "image/png", "logo001");
smtp.send("from@mail.ru", "to@mail.ru", "HTML with an image",
    "<img src='cid:logo001'>", true);

print(smtp.attachments());  // 1

Examples

Basic sending (SSL)

loadPlugin("plugins/smtp.dll");

var smtp = SmtpClient();
smtp.connect("smtp.mail.ru", 465, true);
smtp.login("user@mail.ru", "password");

smtp.send("user@mail.ru", "recipient@yandex.ru",
    "Test", "Hello from the script!");

print(smtp.lastresponse());
smtp.disconnect();

Sending with attachments

loadPlugin("plugins/smtp.dll");

var smtp = SmtpClient();
smtp.connect("smtp.mail.ru", 465, true);
smtp.login("user@mail.ru", "password");

smtp.attach("photo.jpg", "C:\\Photos\\photo.jpg", "image/jpeg");
smtp.attach("data.csv", "C:\\Data\\report.csv", "text/csv");

smtp.send("user@mail.ru", "recipient@yandex.ru",
    "Report", "Files are attached");

print(smtp.attachments());  // 2
smtp.disconnect();

STARTTLS (port 587)

var smtp = SmtpClient();
smtp.connect("smtp.gmail.com", 587, false);
smtp.starttls();
smtp.login("user@gmail.com", "app_password");
smtp.send("user@gmail.com", "dest@gmail.com", "Hi", "Hello!");
smtp.disconnect();

HTML message with an inline attachment

var smtp = SmtpClient();
smtp.connect("smtp.mail.ru", 465, true);
smtp.login("user@mail.ru", "password");

smtp.attach("logo.png", "C:\\logo.png", "image/png", "logo001");

var html = "<h1>Report</h1>" +
    "<p>Attachment:</p>" +
    "<img src='cid:logo001' width='200'>";

smtp.send("user@mail.ru", "recipient@yandex.ru", "HTML report", html, true);
smtp.disconnect();

Error diagnostics

var smtp = SmtpClient();
if (!smtp.connect("smtp.invalid.host", 465, true)) {
    print("Connection error: " + smtp.lastresponse());
}
smtp.connect("smtp.mail.ru", 465, true);
if (!smtp.login("wrong@mail.ru", "wrong_pass")) {
    print("Authentication error: " + smtp.lastresponse());
}
smtp.disconnect();
