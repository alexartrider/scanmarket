SQLite module

Native built-in SQLite with no dependency on QtSql or an external SQLite DLL

RUEN

Home / SQLite

Creation

var db = sqlite.open("data.db");
var memory = sqlite.memory();

The module uses the SQLite amalgamation built together with the application. qsqlite.dll is not required.

Module methods

MethodDescription
sqlite.open(path)Create and open a SQLite database
sqlite.memory()Create an in-memory database
sqlite.version()Version of the built-in SQLite library

Database object methods

MethodDescription
db.exec(sql, params?)Execute INSERT, UPDATE, DELETE or DDL
db.execute(sql, params?)Alias of exec
db.query(sql, params?)Execute SELECT and return an array of tuples
db.scalar(sql, params?)Return the first field of the first row
db.begin(), db.commit(), db.rollback()Transactions
db.changes()Number of changed rows
db.last_insert_rowid()ID of the last inserted row
db.isopen(), db.close()Database state and closing
db.last_error()Text of the last error

Parameters

Positional parameters are passed as an array, named parameters as a tuple. For named parameters the key is specified together with the :, @ or $ prefix.

db.exec("insert into people(name, age) values (?, ?)", #["Alice", 30]);
db.exec("insert into people(name, age) values (:name, :age)", #{
    ":name": "Bob",
    ":age": 41
});

Types

SQLiteScript
NULLnull

Example

var db = sqlite.open("people.db");
db.exec("create table if not exists people(id integer primary key, name text, age integer)");
db.exec("insert into people(name, age) values (?, ?)", #["Alice", 30]);

var rows = db.query("select id, name, age from people order by id");
for (var row : rows) {
    print(row.id + ": " + row.name + ", " + row.age);
}
db.close();
