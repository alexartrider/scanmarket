Clipboard Plugin

Reading and writing text and images to the Windows system clipboard

RUEN

Home / Plugins / Clipboard

Loading the plugin

The plugin uses the Windows system clipboard (Win32). Works in qodeqt, qodegui and qodedesigner.

var ok = loadPlugin(file.apppath() + "/plugins/clipboard.dll");
if (!ok) throw "Failed to load the clipboard plugin";

Text

FunctionArgumentsReturnsDescription
ClipboardGetText()—stringText from the clipboard (UTF-16). Empty string if there is no text
ClipboardSetText(text)textint (0/1)Puts text into the clipboard
ClipboardHasText()—int (0/1)Whether there is text in the clipboard

Images

Image exchange happens through ByteArray. The plugin works with DIB (Device-Independent Bitmap):

  • ClipboardGetImage() returns a complete BMP file (with the "BM" header) — it can be saved to disk right away via file.writebytes;
  • ClipboardSetImage(data) accepts a complete BMP file or a "bare" DIB (data without the file header).

Reading from the clipboard uses the CF_DIB / CF_DIBV5 formats — these are the standard formats that Windows and most applications (Print Screen, browsers, graphics editors) put images into.

FunctionArgumentsReturnsDescription
ClipboardHasImage()—int (0/1)Whether there is an image in the clipboard
ClipboardGetImage()—ByteArray | nullImage as a complete BMP file; null — no image
ClipboardGetImageInfo()—Tuple | nullImage metadata, see below; null — no image
ClipboardSetImage(data)data: ByteArrayint (0/1)Puts an image (BMP file or DIB) into the clipboard

ClipboardGetImageInfo

Returns a tuple:

FieldTypeDescription
widthintImage width, pixels
heightintImage height, pixels
bppintColor depth (1, 4, 8, 16, 24, 32)

Clearing

FunctionArgumentsReturnsDescription
ClipboardClear()—int (0/1)Completely clears the clipboard

Examples

Copying and pasting text

var oldText = ClipboardGetText();      // what was in the clipboard
ClipboardSetText("Hello, world!");
if (ClipboardHasText()) {
    print("In the clipboard: " + ClipboardGetText());
}

Saving an image from the clipboard to a file

if (ClipboardHasImage()) {
    var info = ClipboardGetImageInfo();
    print(info.width + "x" + info.height + ", " + info.bpp + " bpp");

    var img = ClipboardGetImage();        // complete BMP file
    file.writebytes(file.apppath() + "/clipboard.bmp", img);
    print("Saved " + img.size() + " bytes");
}

Putting an image from a file into the clipboard

var data = file.readbytes("picture.bmp");   // ByteArray with a complete BMP file
ClipboardSetImage(data);
print("hasImage: " + ClipboardHasImage());

Moving an image between applications

if (ClipboardHasImage()) {
    ClipboardSetText("The screenshot was copied from the clipboard");
}
