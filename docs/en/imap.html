Connection and Authorization

MethodArgumentsReturnsDescription
connecthost, [port], [tls]int (1/0)Connection to an IMAP server. port defaults to 143 (993 if tls=true). tls — SSL/TLS encryption
starttls—int (1/0)Switch to TLS (after connecting without encryption)
loginuser, passint (1/0)Authorization with login and password
authenticateuser, tokenint (1/0)Authorization via XOAUTH2 (Gmail, Yandex)
disconnect——Closing the connection
ping—int (1/0)NOOP command — keep the connection alive, check activity
getStatus—tupleConnection status

Return value of getStatus()

FieldTypeDescription
connectedint1 — connected, 0 — not
loggedInint1 — authorized, 0 — not
sslEnabledint1 — SSL active, 0 — not
currentFolderstringCurrently selected folder
var imap = ImapClient();

// Connecting to Mail.ru with SSL
var ok = imap.connect("imap.mail.ru", 993, true);
print("Connection: " + ok);  // 1

// Authorization
ok = imap.login("user@mail.ru", "password");
print("Login: " + ok);  // 1

// Checking the status
var st = imap.getStatus();
print("Connected: " + st.connected);     // 1
print("Authorized: " + st.loggedIn);      // 1
print("SSL: " + st.sslEnabled);             // 1
print("Folder: " + st.currentFolder);        // (empty)

// Keeping the connection alive
imap.ping();

Working with Folders

MethodArgumentsReturnsDescription
listfolders[reference], [pattern]arrayFolder list. reference — the base folder, pattern — the search pattern (default "*")
selectfolderintSelect a folder. Returns the number of messages or -1 on error
// Get the list of all folders
var folders = imap.listfolders();
print("Folders: " + folders.size());
for (var i = 0; i < folders.size(); i++) {
    print("  " + folders[i]);
}

// Select INBOX
var count = imap.select("INBOX");
print("Messages in INBOX: " + count);

// Check the selected folder
var st = imap.getStatus();
print("Current folder: " + st.currentFolder);  // INBOX

Searching Messages

MethodArgumentsReturnsDescription
search[criteria]array of intSearch message UIDs by an IMAP criterion. With no arguments — all messages

IMAP Search Criteria

CriterionDescriptionExample
ALLAll messagessearch("ALL")
UNSEENUnreadsearch("UNSEEN")
SEENReadsearch("SEEN")
FROM "string"From the sendersearch("FROM \"user@example.com\"")
TO "string"Recipientsearch("TO \"me@example.com\"")
SUBJECT "string"Message subjectsearch("SUBJECT \"test\"")
BODY "string"Body textsearch("BODY \"important\"")
SINCE dateAfter a datesearch("SINCE 01-Jan-2024")
BEFORE dateBefore a datesearch("BEFORE 31-Dec-2023")
UID min:maxUID rangesearch("UID 1:100")
Larger nLarger than n bytessearch("Larger 1024")
NOT criterionNegationsearch("NOT SEEN")
OR (crit1) (crit2)Logical ORsearch("OR (FROM \"a\") (FROM \"b\")")
// All messages
var all = imap.search("ALL");
print("Total: " + all.size());

// Unread
var unread = imap.search("UNSEEN");
print("Unread: " + unread.size());

// Last 10 messages
var recent = [];
var start = max(0, all.size() - 10);
for (var i = start; i < all.size(); i++) {
    recent.push(all[i]);
}

// Search for UIDs and filter by headers in the script
var uids = imap.search("ALL");
for (var i = 0; i < uids.size(); i++) {
    var h = imap.header(uids[i]);
    if (!h.isnull()) {
        var subj = h["Subject"];
        if (!subj.isnull() && subj.toString().contains("Important")) {
            print("Found: UID=" + uids[i] + "Subject=" + subj);
        }
    }
}

Reading Messages

MethodArgumentsReturnsDescription
headeruidtupleMessage headers as a key-value tuple (From, To, Subject, Date, ...)
fetchuid, [part]stringReading the message content
attachmentsuidarray of tupleAttachment list from BODYSTRUCTURE
fetchattachmentuid, partNo, [path_or_bytes]int / bytearrayDownload an attachment to a file (specify a path) or ByteArray (no path)

part parameters for fetch()

ValueDescription
BODY.PEEK[HEADER]Headers only (does not mark as read)
BODY.PEEK[TEXT]Body only (does not mark as read)
BODY.PEEK[]Headers + body (does not mark as read)
BODY[HEADER]Headers (marks as read)
BODY[TEXT]Body (marks as read)
BODY[]Headers + body (marks as read)
BODY[1]First part (text)
BODY[2]Second part (usually an attachment)

Fields of the return value of attachments()

FieldTypeDescription
partNostringPart number (for fetchattachment)
filenamestringFile name
typestringMIME type (application, text, image...)
subtypestringSubtype (pdf, octet-stream, plain...)
sizeintSize in bytes
var uid = uids[0];

// --- Headers ---
var h = imap.header(uid);
print("From:   " + h["From"]);
print("To:     " + h["To"]);
print("Subject:" + h["Subject"]);
print("Date:   " + h["Date"]);

// --- Message body ---
var body = imap.fetch(uid, "BODY.PEEK[TEXT]");
print(body);

// --- Headers + body (no read mark) ---
var full = imap.fetch(uid, "BODY.PEEK[]");

// --- Attachments ---
var atts = imap.attachments(uid);
print("Attachments: " + atts.size());
for (var i = 0; i < atts.size(); i++) {
    print("  [" + i + "] " + atts[i].filename
        + " (" + atts[i].type + "/" + atts[i].subtype + ") "
        + atts[i].size + " bytes");
}

// --- Download an attachment to a file ---
if (atts.size() > 0) {
    var saved = imap.fetchattachment(uid, atts[0].partNo, "C:/temp/att.pdf");
    print("Saved: " + saved + " bytes");
}

// --- Download an attachment to a ByteArray ---
if (atts.size() > 0) {
    var data = imap.fetchattachment(uid, atts[0].partNo);
    print("Size: " + data.size() + " bytes");
}

Deleting and Managing Flags

MethodArgumentsReturnsDescription
deleteuidint (1/0)Deleting a message: marks \Deleted + EXPUNGE
setflaguid, flag, [value]int (1/0)Setting/unsetting a flag. value: true (default) or false
copyuid, folderint (1/0)Copying a message to another folder
moveuid, folderint (1/0)Moving a message (COPY + STORE \Deleted + EXPUNGE)

IMAP Flags

FlagDescription
\SeenRead
\AnsweredThe message has been replied to
\FlaggedFlagged (important)
\DeletedMarked for deletion
\DraftDraft
// Delete a message (STORE +FLAGS \Deleted + EXPUNGE)
var ok = imap.delete(uid);
print("Deleted: " + ok);

// Mark as read
imap.setflag(uid, "\\Seen");

// Flag as "important"
imap.setflag(uid, "\\Flagged");

// Remove the flag
imap.setflag(uid, "\\Flagged", false);

// Mark as draft
imap.setflag(uid, "\\Draft");

// Copy to the "Backup" folder
imap.copy(uid, "Backup");

// Move to the archive
imap.move(uid, "Archive/2024");

Example: Receiving Mail

if (!loadPlugin("plugins/imap.dll")) {
    print("imap.dll is not loaded!");
    system.exit(1);
}

var imap = ImapClient();
imap.connect("imap.mail.ru", 993, true);
imap.login("user@mail.ru", "password");

// Select INBOX
var count = imap.select("INBOX");
print("Messages: " + count);

// Find unread
var uids = imap.search("UNSEEN");
print("Unread: " + uids.size());

// Read each one
for (var i = 0; i < uids.size(); i++) {
    var h = imap.header(uids[i]);
    if (!h.isnull()) {
        print("--- Message " + uids[i] + " ---");
        print("  From: " + h["From"]);
        print("  Subject: " + h["Subject"]);
        print("  Date: " + h["Date"]);
    }
}

imap.disconnect();

Example: Sending and Deleting

if (!loadPlugin("plugins/smtp.dll")) { system.exit(1); }
if (!loadPlugin("plugins/imap.dll")) { system.exit(1); }

// Sending a message
var smtp = SmtpClient();
smtp.connect("smtp.yandex.com", 465, true);
smtp.login("sender@yandex.ru", "password");
smtp.send("sender@yandex.ru", "recipient@mail.ru",
    "Test", "Hello from QodeScript!");
smtp.disconnect();

// Reading and deleting
var imap = ImapClient();
imap.connect("imap.mail.ru", 993, true);
imap.login("recipient@mail.ru", "password");
imap.select("INBOX");

// Searching by headers
var all = imap.search("ALL");
for (var i = 0; i < all.size(); i++) {
    var h = imap.header(all[i]);
    if (!h.isnull() && h["Subject"].toString() == "Test") {
        print("Found! Deleting...");
        imap.delete(all[i]);
        print("Deleted!");
        break;
    }
}

imap.disconnect();

Example: Working with Folders

var imap = ImapClient();

}

// Move to the archive

Error Handling

var imap = ImapClient();

// Checking the connection
if (!imap.connect("imap.mail.ru", 993, true)) {
    print("Failed to connect!");
    system.exit(1);
}

// Checking the login
if (!imap.login("user@mail.ru", "wrong")) {
    print("Wrong login/password!");
    imap.disconnect();
    system.exit(1);
}

// Checking select
var count = imap.select("INBOX");
if (count == -1) {
    print("Folder not found!");
}

// Checking fetch
var body = imap.fetch(999999);
if (body.isnull()) {
    print("Message not found!");
}

// Checking getStatus()
var st = imap.getStatus();
if (!st.connected) {
    print("Connection lost!");
}

imap.disconnect();
