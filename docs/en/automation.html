Loading

The libraries live in qt/scriptlib/ and are loaded with loadModule — only this way keeps the functions in Script::Modules (unlike execute, which unloads the module right away). It is convenient to compute the path from the executable directory (stable for Debug qt/bind and Release qt/bin):

var scriptlib = file.normalize(file.join(file.dirname(system.getcommandline().app), "..", "scriptlib"));
loadModule(file.join(scriptlib, "qtestlib.prg"));
loadModule(file.join(scriptlib, "cli.prg"));
loadModule(file.join(scriptlib, "funcedit.prg"));
loadModule(file.join(scriptlib, "jsonedit.prg"));
loadModule(file.join(scriptlib, "fileedit.prg"));
loadModule(file.join(scriptlib, "xlsxedit.prg"));

Tests in qt/sample/ load the libraries from the sibling directory: file.join(file.dirname(system.getcommandline().args[0]), "..", "scriptlib", "cli.prg").

Safe file editing (fileedit)

Instant atomic edits (temp file + replace, like file.writeatom) that are also idempotent; opts are the same keys as for writeatom: {"enc","overwrite","backup","verify"}. Without opts, the write follows the old rules (UTF-8 without BOM). If there is nothing to change, the instant edits return 0 and do not write the file (mtime is untouched).

FunctionDescription
fileedit.replaceAll(path, old, new, [opts])Replace all occurrences → 1 (found) / 0 (none)
fileedit.replaceFirst(path, old, new, [opts])Replace only the first occurrence → 1 / 0
fileedit.edit(path, editFn, [opts])editFn(text) → new text, atomically
fileedit.filter(path, lineFn, [opts])Line by line: lineFn(line) → line or null (remove)
fileedit.prepend(path, text, [opts])Insert text at the beginning of the file
fileedit.append(path, text, [opts])Append text to the end (with a newline)
fileedit.replaceAll("app.json", "localhost", "192.168.111.7", #{"backup": 1});
// "edit a function — in one call, not a series of str.replace":
fileedit.edit("tool.prg", function(text) {
    return funcedit.replaceBody(text, "compute", " return a * b; ");
});

Planning and applying (plan/apply)

The «look first, write later» loop for utilities. plan* reads the file, computes the new version, the number of matches and the diff — and writes nothing. apply(plan) re-reads the file before writing and compares it with the content at plan time: on an external change it throws a conflict exception without writing. The write goes through file.writeatom while preserving the source encoding (see below).

FunctionDescription
fileedit.planReplaceAll / planReplaceFirst(path, old, new)Replacement plan (all / first)
fileedit.planEdit(path, editFn)Plan based on an editor function
fileedit.planFilter(path, lineFn)Line-filter plan
fileedit.planPrepend / planAppend(path, text)Insert-at-start / append-to-end plan
fileedit.planContext(path, old, new)Context replace: only on a single match; at 0 or several — plan.diagnostics and apply refuses
fileedit.apply(plan, [opts])Apply the plan → 1 (written) / 0 (nothing to change). opts: {"enc","backup","verify","overwrite","expect"}; expect — expected number of changes (checked against plan.count)

The plan is an ordinary value #{"path","kind","orig","next","count","diff","enc","bom","old","new","diagnostics"}, independent of any global state. Re-applying the same plan does not silently overwrite the file: after the first edit the content is already next ≠ orig → conflict.

var plan = fileedit.planReplaceAll("cfg.txt", "old", "new");
if (plan.count != 1) throw "expected exactly one occurrence";
fileedit.apply(plan, #{"backup": 1});
// an external edit between plan and apply -> fileedit.apply: file changed since planning

Preserving the source file encoding

plan* captures the source file encoding via file.readmeta(path) (fields plan.enc/plan.bom), and apply preserves it on write through file.writeatom. An explicit opts.enc at apply overrides the encoding. Line endings LF/CRLF are not normalized — they are saved as read.

Ambiguous-case policy (documented):

  • ASCII/UTF-8 without BOM → written as UTF-8 without BOM (safe: ASCII ⊂ UTF-8);
  • BOM encodings are distinguished correctly (UTF-8 BOM, UTF-16 LE/BE);
  • UTF-16 BE is not supported by atomic writes → error before replacing the file;
  • UTF-16 LE without BOM → the write would always add a BOM, so the edit is forbidden;
  • unrecognized encoding (file.ENC_UNKNOWN) → error asking to pass enc explicitly.

An ordinary file.writeatom without new options keeps working by the old rules (UTF-8 without BOM by default). Encoding metadata is also available directly: file.readmeta(path) → #{"text","enc","bom"} (see file).

Utility command line (cli)

Schema-driven argument parsing built on system.getcommandline().parsed (ordered tokens: flag/value/positional/--). The schema is a tuple with a params array: #{"name","short","type","default","required","repeat","help"}.

FunctionDescription
cli.parse(schema, [cmdline])Parse → #{"opts","args","help"}; errors are exceptions. cmdline defaults to system.getcommandline()
cli.help(schema)Help text generated from the same schema
loadModule(file.normalize(file.join(file.dirname(system.getcommandline().app), "..", "scriptlib", "cli.prg")));
var schema = #{
    "program": "myutil", "usage": "[options] FILE", "positional": "FILE — input file",
    "params": #[
        #{"name": "output", "short": "o", "type": "string", "default": "out.txt", "help": "result file"},
        #{"name": "verbose", "short": "v", "type": "bool", "help": "verbose output"},
        #{"name": "count", "type": "int", "help": "how many times"},
        #{"name": "mode", "type": "string", "required": 1, "help": "mode"}
    ]
};
var r = cli.parse(schema);       // uses getcommandline().parsed
if (r.help) { print(cli.help(schema)); return 0; }
print("output=" + r.opts.output + " verbose=" + r.opts.verbose + " count=" + r.opts.count);
print("files=" + json.stringify(r.args));

Syntax: long --name/--name=value, short -o (a group -abc is boolean), a value as a separate argument --output result.txt / -o result.txt; -- ends the flags; types string/int/float/bool with value validation; required options and default values; --help/-h (unless the schema declares its own) give r.help=1.

Repeated-parameter policy (documented, not accidental): by default the last value wins (like argparse); a parameter can set "repeat": "error" (error on a repeat) or "repeat": "first" (ignore repeats). ⚠️ Unlike system.getcommandline().flags (there the first value wins because of tuple/emplace).

Limitations: a short flag with a value is only supported as a separate argument (-o value), the -o=value form is not supported; a boolean parameter takes the value only via --name=value (a separate value after the flag is not consumed and becomes positional); a parameter field that collides with a built-in tuple method (size/has/get/set/...) is not accessible via opts.name (a language limitation).

Editing functions in source code (funcedit)

Finds function Name(...) [export|local] { ... } declarations (including inside classes), as well as expression bodies function Name(...) return <exp>; without braces; "function" inside strings and comments is ignored. Changes are made only at the found boundaries. source is the source text.

FunctionDescription
funcedit.find(source, name)Exactly one function → #{"start","bodyStart","bodyClose","end"}, otherwise a clear exception
funcedit.exists(source, name)Whether a match exists → 0/1
funcedit.isUnique(source, name)Exactly one match → 0/1
funcedit.getBody(source, name)Body text (between { and }; for return-functions — “return …” up to the “;”)
funcedit.replaceBody(source, name, newBody)New source with the replaced body
funcedit.replace(source, name, newFuncSource)Replace the whole function
funcedit.insertBefore / insertAfter(source, name, snippet)Insert a snippet before function / after the closing } (for return-functions — after the “;”)
funcedit.balanced(source)Balance of () [] {} accounting for strings/comments → 0/1

JSON forms (jsonedit)

Works with a JSON string (usually the content of a *.json form). Returns a NEW string — the source is not modified.

FunctionDescription
jsonedit.format(jsonText, [indent])Reformat JSON (4 spaces by default)
jsonedit.getText(jsonText, path, [def])Value by path (paths like a.b[0].c)
jsonedit.setText(jsonText, path, value, [indent])JSON string after changing the value by path
jsonedit.validateForm(jsonText)Validate the RuntimeForm structure → #{"ok","errors"}
jsonedit.collectEvents(jsonText)All form/widget events → array of #{"entity","event","handler"}
jsonedit.findWidgetPath(jsonText, name)Path to a widget (e.g. form.widgets[2]) or null
jsonedit.handlerFor(jsonText, entityPath, event)Name of the event handler

Tests (qtestlib) and the runner (run_tests)

FunctionDescription
qt_group(name)Group heading
qt_check(desc, actual, expected)Comparison via ==
qt_checkJson(desc, actual, expected)Comparison via json.stringify
qt_checkExact(desc, actual, expected)Case-sensitive string comparison (the ordinary == does not distinguish case)
qt_ok(desc, cond) / qt_fail(desc, [msg])Boolean check / unconditional FAIL
qt_throws(desc, fn, [pattern])The function must throw an exception (by substring)
qt_tempdir([prefix])Unique temporary directory (all file tests work only there)
qt_quoteArg(a) / qt_run(prog, args, [timeout])Argument quoting / run with captured output
qt_done()Summary of the whole run → 0/1 (at the end of a test: return qt_done();)

A test is an ordinary script that ends with return rc; (the process exit code is 0/1). Running all tests in one call:

qt\bind\qodeqt.exe qt\sample\run_tests.prg                              // all test_*.prg
qt\bind\qodeqt.exe qt\sample\run_tests.prg test_json*.prg               // by pattern
qt\bind\qodeqt.exe qt\sample\run_tests.prg --timeout=30000 test_fileedit.prg

Rules for a robust loop (verified empirically)

  • Exit code: end the program with return 0; (or return rc;) — return N; yields code N. A syntax error in the file returns code 1, an unhandled exception during execution returns code 2 (previously these failures were masked by code 0). Without an explicit return the code is AsInt() of the last expression.
  • Output: print writes to the console window and to the log qt/bin/log/log_DDMMYYYY.log (in parallel), but NOT to the redirectable OS stdout — capturing a child’s stdout yields empty. Check the child run result with a marker file + res.code, not res.stdout.
  • Log location: configurable from the script via Log.localFilePath (and Log.remoteFilePath); if the directory does not exist, it is created recursively automatically (the default path qt/bin/log is still created as before). The log file name prefix is Log.filePrefix.
  • Shell-less launch (paths with spaces/Unicode are safe): system.execArgv(#[exe, arg1, arg2], #{"cwd","timeout","outfile"}).
  • Headless: forms and tables are created without GUI — file.setenv("QT_QPA_PLATFORM","offscreen") BEFORE execArgv.
  • Container mutations inside function parameters are not visible to the caller (COW) — helpers must return a new value.
