Properties (read/write)

PropertyTypeDescription

Connection management methods

MethodDescription
db.connect(driver, connectionString)Establish a database connection
db.disconnect()Close the connection (roll back unfinished transactions)
db.query()Create a query object (BuiltinDbQuery)

Transaction methods

MethodDescription
db.begin()Begin a transaction
db.commit()Commit a transaction
db.rollback()Roll back a transaction

Data insertion methods

MethodDescription
db.insert(table, data, [callback, counter])Row-by-row INSERT (1 SQL per row)
db.insertpacket(table, data, [callback, counter])Batch INSERT ... VALUES (...), (...), (...)
db.insertBatch(table, fields, rows, [callback, counter])Bulk INSERT from an array of fields + an array of values

Examples

// SQLite
db.connect(db.QSQLITE, "mydb.sqlite");

// PostgreSQL
db.connect(db.QPSQL, "host=localhost port=5432 dbname=mydb user=postgres");

// Transaction
db.begin();
db.insert("users", #{"name": "Ivan", "age": 30});
db.commit();

// insertpacket — batch insert
db.insertpacket("logs", #[
    #{"msg": "start", "ts": datetime.now()},
    #{"msg": "end",   "ts": datetime.now()}
]);

// insertBatch — bulk insert
var fields = #["id", "name"];
var rows = #[ #[1, "A"], #[2, "B"], #[3, "C"] ];
db.insertBatch("t1", fields, rows);

// Progress callback
db.insertpacket("big_table", hugeArray, function(count) {
    print("Inserted: \(count)");
}, 1000);

BuiltinDbQuery object (Query)

Created via db.query().

Navigation

MethodDescription
q.first()Move to the first record
q.last()Move to the last record
q.next()Next record
q.prev()Previous record
q.eof()End of the dataset
q.bof()Start of the dataset
q.refresh()Reload the data
q.close()Close the dataset

Data

MethodDescription
q.open(sql)Execute a SELECT query
q.execSQL(sql)Execute INSERT/UPDATE/DELETE
q.field(index|name)Field value by index or name
q.row()Current record as a tuple (read-only)
q.rows()All records as an array of tuples
q.recordcount()Number of records
q.rowsaffected()Rows affected (for INSERT/UPDATE/DELETE)
q.dataset()QtDataSet object (low-level access)
q.parameters()Bound query parameters
q.sql([newSQL])Get/set the SQL text

Field access as properties

q.open("SELECT * FROM users");
while (!q.eof()) {
    print(q.name + " — " + q.age);
    q.next();
}

Example

var q = db.query();
q.open("SELECT name, age FROM users WHERE age > :min");
while (!q.eof()) {
    print(q.field("name") + ": " + q.field("age"));
    q.next();
}

// Via properties
q.open("SELECT * FROM users");
var all = q.rows();  // array of tuples
