QDbGridView — Data Grid

Viewing and editing data from a database in a tabular form

RUEN

Home / QT / QDbGridView

Description

QDbGridView is a table widget (a QTableView subclass) for displaying and editing data from a database. It supports two operating modes:

  • External DataSet — data is passed from the script via setDataSet()
  • Internal DataSet — data is loaded by an SQL query via open()

Properties

PropertyTypeDescription
sqlstringSQL query to load the data
columnsstring (JSON)Column definitions in JSON array format
readOnlyboolRead-only (editing disabled)
showGridLinesboolShow grid lines
autoOpenboolOpen automatically when created on a form

JSON format for columns

[
    {
        "field": "NAME",       // field name in the DB
        "caption": "Name", // column caption
        "width": 150,          // width (default 100)
        "visible": true,       // visibility (default true)
        "align": 1,            // alignment: 1=Left, 2=Right, 4=Center
        "readOnly": false      // read-only (default false)
    }
]

Methods

MethodDescription
open()Open the table by SQL query. Returns true on success
close()Close the table and release the data
refresh()Refresh the data (re-execute the SQL or update the model)
isActive()Whether the table is open (bool)
currentRow()Current row as a tuple keyed by field names (field_name: value); returns an empty tuple if no row is selected. SQL NULL is converted to null
currentRowIndex()Zero-based index of the current row; -1 if no row is selected
setDataSet(ds)Set an external DataSet
dataSet()Get the current DataSet

Examples

External DataSet

var ds = db.open("SELECT * FROM users");
var grid = qt.create("QDbGridView", form);
grid.setDataSet(ds);
grid.columns = '[{"field":"ID","caption":"№","width":50},{"field":"NAME","caption":"Name","width":200}]';
grid.align = "alClient";

For a JSON form with autoOpen: true, connect the database in the form's top-level script: SQL grids open after this code runs, but before the formCreate (OnCreate) handler. Named event handlers must also be declared in the form script so they exist when events are connected. See JSON form lifecycle for the full initialization phases.

Internal DataSet (SQL)

var grid = qt.create("QDbGridView", form);
grid.sql = "SELECT id, name, salary FROM employees WHERE department = 'IT'";
grid.autoOpen = true;
grid.columns = '[{"field":"id","width":50},{"field":"name","width":200},{"field":"salary","width":100,"align":2}]';
grid.align = "alClient";

Event handling

grid.rowDoubleClicked = function(sender, row, rowData) {
    print("Selected row: \(rowData["NAME"])");
};

grid.currentRowChanged = function(sender, row) {
    statusBar.showMessage("Row \(row + 1) of \(sender.model.rowCount)");
};

currentRowChanged passes the row index; this signal form does not depend on QVariantMap conversion. To read a record by index, a separate SQL query with the same ordering can be used to select the corresponding row using database-specific SQL. This is a workaround for currentRow() in versions before the QVariantMap conversion fix.

Manual open/refresh

grid.open();          // open by SQL
grid.refresh();       // refresh the data
var row = grid.currentRow();  // row["product_id"], row["name"]; NULL → null
grid.close();         // close

Lifecycle: close() → change SQL and/or DB → open()

close() closes the internal DataSet: the model and the QSqlQuery are released, so you can safely change SQL and switch connections (db.disconnect() → db.connect()) and call open() again. This is the intended way to reopen a grid after a database change (for example, switching shops in ScanMarket).

  • open() always executes the current sql on the current active connection; changing sql and the connection between close() and open() is reflected correctly in the table.
  • refresh() on an open grid re-executes the SQL on the current connection (fresh data). After close(), refresh does not restore the old model: the grid stays empty.
  • If sql is empty, the connection is unavailable, or the query fails, open() returns false and does not change the displayed data.
grid.close();                 // release the DataSet and the model
db.disconnect();
db.connect(db.QSQLITE, otherFile);
grid.sql = "SELECT ...";
var ok = grid.open();        // new query on the new connection
