Screen plugin (screen capture)

Screenshots — the whole screen, a region, or individual monitors

RUEN

Home / Plugins / Screen

Loading the plugin

The plugin works only on Windows (Win32 GDI). Capture is performed in an interactive user session.

var ok = loadPlugin(file.apppath() + "/plugins/screen.dll");
if (!ok) throw "Failed to load the screen plugin";

Screen information

FunctionArgumentsReturnsDescription
ScreenCount()—intNumber of monitors
ScreenWidth()—intWidth of the primary monitor, px
ScreenHeight()—intHeight of the primary monitor, px
ScreenVirtualRect()—TupleBounds of the virtual desktop, see below
ScreenMonitors()—Array<Tuple>List of all monitors, see below

ScreenVirtualRect() returns the tuple {left, top, width, height} — the region covering all monitors. The origin of the virtual screen is the top-left corner of the primary monitor, so with a monitor to the left/above, the left/top coordinates are negative.

ScreenMonitors() returns an array of tuples:

FieldTypeDescription
left, topintMonitor position in virtual screen coordinates
width, heightintMonitor resolution, px
primaryint (0/1)1 — primary monitor

Screen capture

The capture result is a complete BMP file (32 bits per pixel) as a ByteArray. It can be saved to disk right away via file.writebytes, passed to the clipboard by the clipboard plugin (ClipboardSetImage), or processed with byte functions.

FunctionArgumentsReturnsDescription
ScreenCapture([cursor])cursor: 0/1 (default 0)ByteArray (BMP) | nullSnapshot of the entire primary monitor
ScreenCaptureRect(x, y, w, h, [cursor])x, y, w, h, cursor: 0/1ByteArray (BMP) | nullSnapshot of a rectangular region of the virtual screen

Notes:

  • ScreenCaptureRect coordinates are given in the virtual screen coordinate system (see ScreenVirtualRect).
  • Parts of the region outside the screens are filled with black.
  • With cursor = 1, the system cursor is added to the snapshot (at its actual position).

Examples

Full-screen screenshot with the cursor

var shot = ScreenCapture(1);           // with the cursor
if (!shot.isnull())
    file.writebytes(file.apppath() + "/screen.bmp", shot);

Region snapshot and copying to the clipboard

var img = ScreenCaptureRect(0, 0, 640, 480);
if (!img.isnull()) {
    loadPlugin(file.apppath() + "/plugins/clipboard.dll");
    ClipboardSetImage(img);            // now it can be pasted into any editor
}

Screenshot of all monitors

var v = ScreenVirtualRect();
var all = ScreenCaptureRect(v.left, v.top, v.width, v.height);  // the entire virtual desktop
file.writebytes("all_monitors.bmp", all);

// Or one monitor at a time:
for (var m : ScreenMonitors())
    file.writebytes("monitor_" + m.left + "_" + m.top + ".bmp",
                    ScreenCaptureRect(m.left, m.top, m.width, m.height));
