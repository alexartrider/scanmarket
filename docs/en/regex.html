Testing and searching

FunctionDescription
regex.match(s, pattern)Whether the whole string matches the pattern (true/false)
regex.search(s, pattern)Whether it contains a substring matching the pattern (true/false)

Extraction

var m = regex.findall("a=1, b=2", "(\\w)=(\\d)");
print(m[0][0]); // "a"
print(m[0][1]); // "1"

No groups — an array of matches. One group — an array of values. Multiple groups — an array of tuples.

Replacement and splitting

FunctionDescription
regex.replace(s, pattern, repl)Replaces ALL occurrences
regex.sub(pattern, repl, s, [count])Replaces up to count occurrences (-1 = all)
regex.split(s, pattern)Splits by the pattern
regex.escape(s)Escapes special characters

Patterns use the ECMAScript syntax of the std::regex implementation. Strings are converted to UTF-8, but regex operates on bytes, so classes such as \w and character boundaries are not Unicode-aware. Invalid patterns are caught by module functions; string methods such as .regexmatch() and .regexsearch() may throw for an invalid pattern.
