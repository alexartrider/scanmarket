QXlsxDocument - Working with Excel files

The qt.XlsxDocument() class provides an API for reading/writing XLSX files via Qt. Available only in GUI projects (qodeqt, qodegui).

Main methods

MethodDescription
doc.open(filename)Opens an existing XLSX file. Supported formats: .xlsx, .xls (via conversion), .csv
doc.create(filename)Creates a new file. If the file exists - overwrites it
doc.save()Saves to the current file
doc.saveAs(filename)Saves to another file
doc.saveAsCSV(filename)Exports data to a CSV file (without formatting)

Working with data

doc.read(row, col)Reads a cell (1-based indices). Returns a QVariant
doc.write(row, col, value)Writes a value. Supports: numbers, strings, dates, booleans
doc.readAll()Returns an array of arrays (QVariantList) with all data
var doc = qt.XlsxDocument();    // or
var doc = qt.QXlsxDocument();

Returns a QXlsxDocument object (via QtAdapter). Available only in GUI projects (qodeqt, qodegui).

Usage examples

Basic example

var doc = qt.XlsxDocument();
        doc.open("data.xlsx");
        
        // Reading data
        var rows = doc.readAll();
        for (var i = 0; i < rows.size(); i++) {
            print(rows[i][0] + " | " + rows[i][1]);
        }
        
        // Writing data
        doc.write(2, 1, "New value");
        doc.save();

Working with sheets

doc.addSheet("Reports");
        doc.selectSheet(1);
        doc.write(1, 1, "Data from the second sheet");

Compatibility and limitations

  • Supports XLSX (Office 2007+), CSV, XLS (via conversion)
  • Maximum number of rows: 1,048,576
  • Maximum number of columns: 16,384
  • Cell formatting (color, font) is not preserved when reading/writing

Data types

Supported types:

  • Numbers (integers, floating point)
  • Strings
  • Dates (YYYY-MM-DD format)
  • Boolean values (true/false)

Performance tips

  • Use readAll() only for small files (<10k rows)
  • For bulk writing, use write(row, col, value) in a loop
  • Avoid frequent save() calls - prefer saveAs() when needed
