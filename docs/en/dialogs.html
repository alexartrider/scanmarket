Dialog functions

FunctionDescription
dialog.showmessage(text, [parent])Message box with text and an OK button
dialog.yesno(text, [parent])Yes/No question. Returns "yes" or "no"
dialog.yesnocancel(text, [parent])Yes/No/Cancel question. Returns "yes", "no" or "cancel"
dialog.inputbox(title, label, default)Single-line input. Returns the entered text
dialog.inputquery(title, labels, defaults)Multi-line input (arrays or a tuple)

Examples

dialog.showmessage("Hello!");

var answer = dialog.yesno("Delete the file?");
if (answer == "yes") { ... }

var name = dialog.inputbox("Enter a name", "Name:", "Ivan");
var vals = dialog.inputquery("Data", #{"Name": "", "Age": "25"});
if (vals) print(vals.Name);
