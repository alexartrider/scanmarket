INI/CSV Plugin

Reading and writing INI and CSV files

RUEN

Home / Plugins / INI/CSV

Loading the plugin

loadPlugin("plugins/inicsv.dll");

INI — Reading

iniRead(filename)

Reads an INI file and returns a tuple of tuples: #{"section": #{"key": value, ...}, ...}

  • Numbers are automatically converted to int or double
  • Comments (; and #) are skipped
  • Empty sections/values are allowed
var data = iniRead("config.ini");
print(data.database.host);   // "localhost"
print(data.database.port);   // 5432 (int)
print(data.server.bind);     "0.0.0.0"

iniReadValue(filename, section, key)

Reads a single specific value. Returns null if not found.

var host = iniReadValue("config.ini", "database", "host");
print(host);  // "localhost"

var missing = iniReadValue("config.ini", "noexist", "key");
print(missing);  // null

INI — Writing

iniWrite(filename, data, [encoding])

Writes a tuple of sections to an INI file. Each section is a tuple of values.

ArgumentTypeDefaultDescription
filenamestring—File path
datatuple—#{"section": #{"key": val, ...}, ...}
encodingstringkeep the file's encoding"utf8", "utf8bom", "utf16", "cp1251"; for a new file the default is "cp1251"
var config = #{
    "database": #{
        "host": "localhost",
        "port": 5432,
        "name": "mydb"
    },
    "server": #{
        "bind": "0.0.0.0",
        "timeout": 30
    }
};
iniWrite("config.ini", config, "utf8");

Result:

[database]
host=localhost
port=5432
name=mydb

[server]
bind=0.0.0.0
timeout=30

iniWriteValue(filename, section, key, value, [encoding])

Writes/updates a single value. If the file exists — updates it in place. If not — creates it.

ArgumentTypeDescription
filenamestringFile path
sectionstringSection name
keystringKey name
valueanyValue (string/int/double/bool)
encodingstringEncoding; if not specified — the encoding of the existing file is kept, for a new file — cp1251
// Creates the file from scratch
iniWriteValue("settings.ini", "main", "debug", true, "utf8");
iniWriteValue("settings.ini", "main", "port", 8080, "utf8");

// Updates an existing value
iniWriteValue("settings.ini", "main", "port", 9090, "utf8");

// Adds a new section to an existing file
iniWriteValue("settings.ini", "network", "timeout", 30, "utf8");

CSV — Reading

csvRead(filename, fields, [encoding], [separator])

Reads a CSV file and returns an array of tuples. Each row is a tuple with keys taken from the header.

ArgumentTypeDefaultDescription
filenamestring—File path
fieldsstring/array—String "a;b;c" or array #[a, b, c]
encodingstring"cp1251"Encoding
separatorstring";"Separator (";", ",", "\t")

Automatic value parsing:

  • null → empty strings
  • int → integers
  • double → floating-point numbers
  • true/yes → 1, false/no → 0
  • Everything else — a string

Full RFC-like parsing:

  • quoted fields, including multi-line ones (line breaks inside a value);
  • separators and quotes inside a field; "" is an escaped quote;
  • line endings CRLF, LF, CR; BOM at the start of the file;
  • empty lines are ignored, empty and trailing fields are preserved;
  • whitespace around a field outside quotes is trimmed, inside quotes — preserved;
  • keys are taken from the file header; missing expected fields are filled with null.
// Field list as a string with separators
var rows = csvRead("data.csv", "name;age;city", "utf8");
print(rows[0].name);   // "Ivan"
print(rows[0].age);    // 30

// Array of fields
var rows = csvRead("data.csv", #["name", "age", "city"], "utf8");

// Comma as separator
var rows = csvRead("data.csv", #["x", "y"], "utf8", ",");

// With tab
var rows = csvRead("data.tsv", "a;b;c", "utf8", "\t");

CSV — Writing

csvWrite(filename, fields, data, [encoding], [separator])

Writes an array of tuples to a CSV file. Returns 1 on success, 0 on error.

ArgumentTypeDescription
filenamestringFile path
fieldsstring/arrayString "a;b;c" or array #["a","b","c"]
dataarrayArray of tuples #[{...}, {...}]
encodingstring"utf8", "utf8bom", "utf16", "cp1251"; not specified — the encoding of the existing file is kept, for a new file — cp1251
separatorstringSeparator (default ";")
var data = #[
    #{"name": "Ivan", "age": 30, "city": "Moscow"},
    #{"name": "Anna", "age": 25, "city": "SPb"}
];

// Semicolon (default)
csvWrite("data.csv", #["name", "age", "city"], data, "utf8");

// Comma
csvWrite("data.csv", #["name", "age", "city"], data, "utf8", ",");

// Field list as a string
csvWrite("data.csv", "name;age;city", data, "utf8");

CSV — Helpers

csvRowCount(filename)

Returns the number of data rows (excluding the header).

var n = csvRowCount("data.csv");
print("Rows: " + n);

Examples

Application configuration

loadPlugin("plugins/inicsv.dll");

var configFile = "app.ini";

// Create the config
var config = #{
    "app": #{
        "name": "MyApp",
        "version": "1.0",
        "debug": true
    },
    "database": #{
        "host": "localhost",
        "port": 5432
    }
};
iniWrite(configFile, config, "utf8");

// Read it
var cfg = iniRead(configFile);
print(cfg.app.name);       // "MyApp"
print(cfg.database.port);  // 5432

// Change a single value
iniWriteValue(configFile, "database", "port", 3306, "utf8");

Processing CSV data

loadPlugin("plugins/inicsv.dll");

// Reading data
var users = csvRead("users.csv", "name;email;age", "utf8");
print("Users: " + csvRowCount("users.csv"));

for (var user : users) {
    print(user.name + " (" + user.email + "), age: " + user.age);
}

// Filtering and writing
var adults = [];
for (var u : users) {
    if (u.age >= 18) adults.push(u);
}
csvWrite("adults.csv", "name;email;age", adults, "utf8");

CSV with commas

// Reading standard CSV
var rows = csvRead("export.csv", #["id", "name", "value"], "utf8", ",");

// Writing standard CSV
csvWrite("output.csv", #["id", "name", "value"], rows, "utf8", ",");

Tabular data

// TSV (Tab-Separated Values)
var data = csvRead("data.tsv", "col1;col2;col3", "utf8", "\t");

// Writing with automatic type detection
var output = #[
    #{"id": 1, "name": "first", "value": 3.14},
    #{"id": 2, "name": "second", "value": 2.71}
];
csvWrite("result.tsv", "id;name;value", output, "utf8", "\t");

File formats

INI

; comments start with ; or #
[section_name]
key1=value1
key2=42
key3=3.14

[another_section]
host=localhost
port=5432

CSV

name;age;city
Ivan;30;Moscow
Anna;25;SPb
"He said ""hello""";25;NY

Values containing quotes, separators, leading/trailing whitespace or line breaks are automatically wrapped in double quotes. Double quotes inside values are doubled: " → "". Rows are separated by CRLF.

Encodings

ParameterDescription
"utf8"UTF-8 without BOM
"utf8bom"UTF-8 with BOM
"utf16"UTF-16 LE
"cp1251"Windows-1251 (default)

Reading automatically detects the encoding (BOM + heuristic).

If no encoding is given when writing (or "auto" is passed) and the file already exists — its encoding is kept; for a new file "cp1251" is used. This lets you update UTF-8/UTF-16 files without specifying the encoding on every call.

Notes

  • Numbers: the decimal separator is always a dot (.), regardless of the system locale
  • Types: empty strings → null, integers → int, floats → double, true/yes → 1, false/no → 0
  • CSV quotes: values containing separators, quotes or line breaks are automatically wrapped in "
  • INI comments: lines starting with ; or # are skipped; a section header may end with a comment: [section] ; note. Comments inside values are not stripped
