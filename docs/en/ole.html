OLE module — Component Object Model (Windows)

Access to COM objects through IDispatch

RUEN

Home / OLE

Functions

FunctionDescription
ole.create(progId)Creates a COM object by ProgID (e.g. "Excel.Application")
ole.getActive(progId)Retrieves an already running COM object
ole.isAvailable(progId)Checks whether the COM class is available (bool)

Example

var excel = ole.create("Excel.Application");
excel.Visible = true;
var wb = excel.Workbooks.Add();
var sheet = wb.Sheets(1);
sheet.Cells(1, 1).Value = "Hello";
wb.SaveAs("C:\\test.xlsx");
excel.Quit();

Properties and methods of an OLE object

Properties and methods of a COM object are accessed with dot notation. Names are case-insensitive.

Properties

obj.PropertyName           // read
obj.PropertyName = value   // write

Methods

obj.MethodName(arg1, arg2)  // method call

Examples

// Word
var word = ole.create("Word.Application");
word.Visible = true;
var doc = word.Documents.Add();
doc.Content.Text = "Hello, World!";
doc.SaveAs2("C:\\doc.docx");
word.Quit();

// Get the active instance
var excel = ole.getActive("Excel.Application");
if (excel) {
    print("Excel is already running");
}

Limitations

  • Available on Windows only (OLE/COM)
  • Arrays are converted to SAFEARRAY (1D and 2D)
  • The VT_DISPATCH type is returned as an OLE object
  • 3D+ arrays are not supported
