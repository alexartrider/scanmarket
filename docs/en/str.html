Searching and checking

Note: the functions str.find and str.contains do not exist. Use str.pos() to find a position and str.count() to count occurrences.

FunctionDescription
str.pos(s, sub)Position of the first occurrence, or -1
str.rpos(s, sub)Position of the last occurrence, or -1
str.count(s, sub)Number of substring occurrences
str.startswith(s, prefix)Whether the string starts with prefix
str.endswith(s, suffix)Whether the string ends with suffix
str.findany(s, chars)Position of the first character from the set chars
str.findnot(s, chars)Position of the first character NOT in the set chars
var s = "Hello World";
print(str.pos(s, "World"));     // 6
print(str.count(s, "l"));       // 3
print(str.startswith(s, "He"));  // true
print(str.endswith(s, "ld"));    // true

Padding and alignment

Note: the third argument pad is a numeric character code (int), not a string:

FunctionDescription
str.pad(s, width, charCode)Pad on the right. charCode is the int code of the character
str.zfill(s, width)Pad with zeros on the left
str.center(s, width, [fill])Center
str.ljust(s, width, [fill])Left-align
str.rjust(s, width, [fill])Right-align
// Padding with dots (46 is the code of '.'):
print(str.pad("hi", 5, 46));   // "hi..."

print(str.zfill("42", 5));      // "00042"
print(str.center("hi", 6));    // "  hi  "

Conversions

FunctionDescription
str.toString(val)To a string
str.toInt(s)To an integer
str.toDouble(s)To a floating-point number
str.itoa(n)Integer → string
str.atof(s)String → floating-point number
str.atoi(s)String → integer
str.hex(n)To hex (with the 0x prefix)
str.bin(n)To binary (with the 0b prefix)
str.oct(n)To octal (with the 0o prefix)
str.fromCharCode(code)Unicode code point 0..0x10FFFF → string
print(str.hex(255));    // "0xFF"
print(str.bin(5));     // "0b101"
print(str.oct(8));     // "0o10"
var emoji = str.fromCharCode(0x1F600);
print(emoji.codepointat(0)); // 128512; independent of console encoding
