Console ANSI codes

For colored output in the console (print).

ConstantDescription
colors.ansiResetReset formatting
colors.ansiBoldBold text
colors.ansiUnderlineUnderline
colors.ansiBlack ... colors.ansiWhiteBasic text colors
colors.ansiBrightBlack ... colors.ansiBrightWhiteBright text colors
colors.ansiGrayBgGray background
colors.ansiGrayFgGray text

Example

print(colors.ansiRed + "Error!" + colors.ansiReset);
print(colors.ansiBold + colors.ansiGreen + "OK" + colors.ansiReset);
