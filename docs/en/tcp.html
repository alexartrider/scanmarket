TcpClient — TCP client

Creates a TCP client for connecting to a server. Data is received by a background thread and buffered.

Creation

// Anonymous client
var client = TcpClient();

// Named client (accessible again by calling its name)
var client = TcpClient("myClient");

Client properties

namestringInstance name (empty string if anonymous)

connect(host, port, [family])

Connects to a TCP server. Performs a non-blocking connection with a 5 second timeout. On a successful connection a background data receiving thread is started.

ArgumentTypeDefaultDescription
hoststring—Server address (domain or IP)
portint—Port number
familyintAF_INET (2)Address family: AF_INET=IPv4, AF_INET6=IPv6
var client = TcpClient();
client.connect("127.0.0.1", 9000);
print(client.connected);  // 1

// IPv6
client.connect("::1", 9000, 23);

send(data)

Sends data to the server. Accepts a string or a ByteArray.

// Sending a string
client.send("Hello!");

// Sending a ByteArray
var bytes = ByteArray();
bytes.append(0x48);  // H
bytes.append(0x49);  // I
client.send(bytes);

sendline(text)

Sends a string with an automatic \n appended at the end.

client.sendline("Hello server");
// Equivalent to: client.send("Hello server\n")

recv([maxBytes], [asText])

Reads data from the internal buffer (does not block the thread). If there is no data — returns null.

ArgumentTypeDefaultDescription
maxBytesint1024Maximum number of bytes to read
asTextboolfalsetrue — return a string, false — ByteArray
// Reading as a ByteArray
var raw = client.recv(1024);
print(typeName(raw));  // "bytearray" or "null"

// Reading as a string
var text = client.recv(1024, true);
print(text);

recvline([timeoutMs])

Reads one line from the buffer (up to \n). Blocks the thread until a line appears or the timeout expires. The \r character before \n is removed automatically.

ArgumentTypeDefaultDescription
timeoutMsint5000Timeout in milliseconds
// Reading with a 3 second timeout
var line = client.recvline(3000);
if (line != null) {
    print(line);
} else {
    print("Timeout!");
}

getpeername()

Returns the address of the connected peer as a tuple. Useful for determining the client's IP address on the server side.

var peer = client.getpeername();
if (peer != null) {
    print(peer.ip);    // "127.0.0.1"
    print(peer.port);  // 54321
}

TcpServer — TCP server

Creates a TCP server for listening to incoming connections. Clients are accepted automatically in a background thread.

Creation

// Anonymous server
var server = TcpServer();

// Named server
var server = TcpServer("myServer");

Server properties

PropertyTypeDescription
listeningint1 if listening, 0 if not
portintPort number
namestringInstance name

Server methods

MethodArgumentsReturnsDescription
listenport, [bindAddr], [backlog]intStarts listening. Stops the previous one
stop—intStops the server and disconnects all clients
islistening—intChecks the state (1/0)
port—intMethod: port number
clients—arrayArray of connected TcpClient
clientcount—intNumber of connected clients
broadcastdataintSends to all clients. Returns the total bytes
setonconnectfuncintConnection handler: func(client)

listen(port, [bindAddr], [backlog])

Starts listening for incoming TCP connections. If the server is already listening — the previous listening and all clients are closed automatically.

ArgumentTypeDefaultDescription
portint—Port number
bindAddrstring"0.0.0.0"Bind address (all interfaces / a specific IP)
backlogint10Queue of pending connections
var server = TcpServer();
server.listen(9000);
print(server.listening);  // 1

// Localhost only
server.listen(9000, "127.0.0.1");

// With a larger backlog
server.listen(9000, "0.0.0.0", 50);

setonconnect(callback)

Sets the handler called for every new client. The function argument is the TcpClient object of the connected client.

Important: the handler is called in the background accept thread. Do not block it for long.

var server = TcpServer();
server.listen(9000);

server.setonconnect(function(client) {
    print("New client!");
    print("Address: " + client.getpeername().ip);

    // Greeting
    client.sendline("Welcome!");

    // Reading data
    var line = client.recvline(5000);
    if (line != null) {
        print("Response: " + line);
        client.sendline("Received: " + line);
    }
});

broadcast(data)

Sends data to all connected clients at once. Returns the total number of bytes sent.

// Broadcast to everyone on a new connection
server.setonconnect(function(client) {
    server.broadcast("New user!");
});

// Relay a message from a client to everyone
function relay(sender, msg) {
    var clients = server.clients();
    for (var c : clients) {
        c.sendline(msg);
    }
}

clients()

Returns an array of all connected clients (TcpClient). Disconnected ones are removed automatically.

var clients = server.clients();
print("Connected: " + clients.size());

// Sending to everyone manually
for (var c : clients) {
    if (c.connected) {
        c.sendline("Ping");
    }
}

Examples

Basic echo server

loadPlugin("tcp");

var server = TcpServer();
server.listen(9000);
print("Server started on port 9000");

var client = TcpClient();
client.connect("127.0.0.1", 9000);

var msg = client.recvline(3000);
print("From server: " + msg);

client.disconnect();
server.stop();

Multi-client chat

loadPlugin("tcp");

var server = TcpServer();
server.listen(8080);

server.setonconnect(function(client) {
    var name = client.recvline(3000);
    server.broadcast(name + " joined the chat");

    while (client.connected) {
        var line = client.recvline(10000);
        if (line == null) break;
        server.broadcast(name + ": " + line);
    }

    server.broadcast(name + " left the chat");
});

print("Chat server started on port 8080");

HTTP server (minimal)

loadPlugin("tcp");

var server = TcpServer();
server.listen(8080);

server.setonconnect(function(client) {
    var request = client.recvline(2000);
    if (request != null) {
        // Skipping headers
        while (true) {
            var header = client.recvline(500);
            if (header == null || header == "") break;
        }

        // Response
        var body = "<h1>Hello, world!</h1>";
        var response =
            "HTTP/1.1 200 OK\r\n" +
            "Content-Type: text/html; charset=utf-8\r\n" +
            "Content-Length: " + body.size() + "\r\n" +
            "Connection: close\r\n" +
            "\r\n" + body;
        client.send(response);
    }
    client.disconnect();
});

print("HTTP server: http://127.0.0.1:8080");

Named instances

loadPlugin("tcp");

// Creating a named server
var s = TcpServer("main");
s.listen(8080);

// Calling again — returns the same object
var same = TcpServer("main");
print(same.listening);  // 1

// Named client
var c = TcpClient("worker");
c.connect("127.0.0.1", 8080);

// Calling again — returns the same object
var same_client = TcpClient("worker");
print(same_client.connected);  // 1

Working with ByteArray (binary protocol)

loadPlugin("tcp");

var server = TcpServer();
server.listen(7000);

server.setonconnect(function(client) {
    // Reading binary data
    var raw = client.recv(1024);
    if (raw != null) {
        print("Bytes received: " + raw.size());
    }
});

var client = TcpClient();
client.connect("127.0.0.1", 7000);

// Sending binary data
var packet = ByteArray();
packet.append(0x01);  // command
packet.append(0x00);  // parameter
packet.append(0xFF);  // checksum
client.send(packet);

client.disconnect();
server.stop();

Simple TCP client

loadPlugin("tcp");

var client = TcpClient();
if (!client.connect("192.168.1.100", 5000)) {
    print("Could not connect!");
    return;
}

client.sendline("PING");
var response = client.recvline(5000);
if (response == "PONG") {
    print("Server is up!");
}

print("Peer: " + client.getpeername().ip);
client.disconnect();

Notes

  • Non-blocking I/O. All sockets work in non-blocking mode. Data is received by a background thread and buffered.
  • recv() — non-blocking. Reads from the buffer, returns null if there is no data.
  • recvline() — blocking. Waits for a line up to \n with the given timeout (5 sec by default).
  • A repeated listen() automatically closes the previous listening and all clients.
  • Server clients (created on connection) are removed automatically on disconnect.
  • Named instances are returned again when calling TcpClient("name") / TcpServer("name").
  • Thread safety. All client and server methods are thread-safe.
  • Cleanup. When the script ends, all sockets and threads are released automatically.
