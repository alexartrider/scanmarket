json module

Working with JSON — parsing, serialization and validation (rapidjson)

RUEN

Home / json

Access

The json module is available globally without uses:

print(typeName(json));  // object

Functions

FunctionDescription
json.parse(string)Parses a JSON string. Objects {} → tuple, arrays [] → array
json.stringify(value)Value → JSON string (compact form)
json.stringify(value, true)Pretty-printed output with indentation (4 spaces)
json.stringify(value, true, indent)Pretty-printed output with the given indentation (number of spaces)
json.formatText(jsonText, [indent])Format JSON text directly through RapidJSON DOM, without round-tripping types through ScriptValue
json.getText(jsonText, path)Get a JSON value by path as a JSON fragment, preserving boolean/object/array types
json.replaceText(jsonText, path, replacementJsonText, [pretty], [indent])Replace a value by path with a JSON fragment while preserving JSON types
json.setFieldText(jsonText, objectPath, key, replacementJsonText)Set an object field by path (including in an empty QRXL cell) without passing through ScriptValue
json.validate(string)Checks whether the JSON is valid → true / false

Type mapping

JSONScriptNote
object {}tuple #{"key": val}JSON objects become tuples
array []array #[...]JSON arrays are regular arrays
stringstring
number (int)int
number (float)double
true / falseint (1 / 0)Boolean values are stored as int
nullnull

⚠ Boolean values (true/false) are output as 1/0 on serialization, because the script has no separate bool type — they are stored as int.

Examples

Parsing

var j = json.parse("{\"name\": \"Ivan\", \"age\": 30}");
print(j.name);  // Ivan
print(j.age);   // 30
print(typeName(j));  // tuple

Parsing with nested objects

var data = json.parse("{
    \"user\": {
        \"name\": \"Petr\",
        \"scores\": [10, 20, 30]
    }
}");
print(data.user.name);       // Petr
print(data.user.scores[1]);  // 20

Serialization

var obj = #{"name": "Ivan", "age": 30};
print(json.stringify(obj));       // {"age":30,"name":"Ivan"}
print(json.stringify(obj, true)); // pretty-printed output

Serialization with a custom indent

print(json.stringify(obj, true, 2));  // 2 spaces

Validation

print(json.validate("{\"a\": 1}"));  // true
print(json.validate("{broken}"));   // false

Array

var arr = json.parse("[1, 2, 3]");
print(typeName(arr));  // array
print(arr[0]);         // 1
