COM Ports Plugin

Working with serial COM ports

RUEN

Home / Plugins / COM ports

Loading the plugin

loadPlugin("plugins/comport.dll");

Creating the object

ComPort([name])

Creates a COM port object. If name is specified — a named instance (singleton: a repeat call with the same name returns the same object).

var port = ComPort();            // anonymous
var port = ComPort("myport");    // named

Properties

PropertyTypeDefaultDescription
portint1COM port number
baudrateint115200Baud rate (bp/s)
bytesizeint8Byte size (7/8)
stopbitsint0Stop bits (see constants)
parityint0Parity (see constants)
timeoutint3000Timeout in ms
namestring""Name of the named instance (R/O)

Constants

ConstantValueDescription
PAR_NONE0No parity
PAR_ODD1Odd parity bit
PAR_EVEN2Even parity bit
PAR_MARK3Mark
PAR_SPACE4Space
PAR_PROGRAM7-17 data bits + software parity
STOP_101 stop bit
STOP_1_511.5 stop bits
STOP_222 stop bits

Methods

open([overlapped])

Opens the port. Returns 1 on success, 0 on error.

ArgumentTypeDefaultDescription
overlappedbooltrueAsynchronous I/O mode

close()

Closes the port. Returns 1.

isopen()

Returns 1 if the port is open, 0 if it is closed.

write(data)

Writes data to the port.

ArgumentTypeDescription
datastring / ByteArrayData to write

Returns the number of bytes written.

writeline(text)

Writes a string + \r\n. Returns the number of bytes written.

read([maxBytes], [asText])

Non-blocking read from the internal queue.

ArgumentTypeDefaultDescription
maxBytesint1024Maximum bytes
asTextboolfalseReturn a string instead of a ByteArray

Returns a ByteArray (or string), or null if there is no data.

readline([timeout])

Blocking read of a line up to \n.

ArgumentTypeDefaultDescription
timeoutint3000Timeout in ms

Returns the string, or null on timeout.

available()

Number of bytes in the internal queue (non-blocking).

getready()

Number of bytes in the hardware buffer (via ClearCommError).

clear()

Clears all buffers (hardware + internal queue). Returns 1.

clearrx() / cleartx()

Clears only the receive / transmit buffer.

listports()

Returns an array of strings with the names of the available COM ports.

var ports = ComPort().listports();
print(ports);  // ["COM1", "COM3", "COM5"]

setondata(callback)

Sets a callback invoked when data arrives.

port.setondata(function(data) {
    print("Received: " + data);
});

Examples

Basic usage

loadPlugin("plugins/comport.dll");

var port = ComPort();
port.port = 3;
port.baudrate = 9600;
port.bytesize = 8;
port.parity = port.PAR_NONE;
port.stopbits = port.STOP_1;

if (port.open()) {
    port.writeline("Hello");
    system.sleep(0.5);

    var response = port.readline(3000);
    if (response != null) {
        print("Response: " + response);
    }

    var data = port.read(1024, true);
    if (data != null) {
        print("Data: " + data);
    }

    port.close();
}

Enumerating ports

var ports = ComPort().listports();
for (var p : ports) {
    print("Found: " + p);
}

Named ports

// Creates a port named "meter"
var meter = ComPort("meter");
meter.port = 5;
meter.baudrate = 115200;
meter.open();

// Somewhere else in the code — get the same object
var m = ComPort("meter");
m.writeline("READ");

Callback on data reception

var port = ComPort();
port.port = 3;
port.baudrate = 9600;
port.open();

port.setondata(function(data) {
    print("Received " + size(data) + " bytes");
});

Software parity (7 bits)

var port = ComPort();
port.parity = port.PAR_PROGRAM7;
port.open();

// Writing: the high bit is the parity bit
port.write("Hello");

// Reading: the high bit is discarded
