xml module

Working with XML — parsing, creating and modifying documents (pugixml)

Access

The xml module is available globally without uses:

print(typeName(xml));  // object

Module functions

FunctionDescription
xml.parse(string)Parse an XML string → XmlDocument
xml.load(path)Load XML from a file → XmlDocument
xml.create(rootName)Create a new document with a root element → XmlDocument

XmlDocument methods

MethodDescription
doc.child(name)First child element by name → XmlNode
doc.children()All child elements of the root → array of XmlNode
doc.print()Serialize the document to a string (indented)
doc.save(path)Save to a file (indented by default)
doc.save(path, false)Save without indentation
doc.set_root(name)Add a root element → XmlNode

XmlNode methods

MethodDescription
node.name()Element name
node.value()Value of the value attribute (or an empty string)
node.set_value(val)Set the value
node.text()Text content of the element
node.set_text(val)Set the text content
node.attribute(name)Value of an attribute by name (or null)
node.set_attribute(name, val)Set or create an attribute
node.child(name)First child element by name → XmlNode
node.children()All child elements → array of XmlNode
node.parent()Parent element → XmlNode
node.next_sibling()Next sibling element → XmlNode
node.prev_sibling()Previous sibling element → XmlNode
node.append_child(name)Add a child element → XmlNode
node.remove_child(name)Remove a child element by name → bool
node.attributes()All attributes → array of tuples #{"name": ..., "value": ...}
node.empty()true if the element is empty
node.print()Serialize the subtree to a string (indented)

Examples

XML parsing

var doc = xml.parse("<root><name>Ivan</name><age>30</age></root>");
print(typeName(doc));  // object

var root = doc.child("root");
print(root.name());           // root
print(root.child("name").text());  // Ivan
print(root.child("age").text());   // 30

Document output

print(doc.print());
// <?xml version="1.0"?>
// <root>
//     <name>Ivan</name>
//     <age>30</age>
// </root>

Creating XML

var doc = xml.create("catalog");
var root = doc.child("catalog");

var item = root.append_child("item");
item.set_attribute("id", "1");
item.append_child("title").set_text("Book");
item.append_child("price").set_text("500");

print(doc.print());

Loading from a file

var doc = xml.load("data.xml");
var items = doc.child("root").children();
for (var item : items) {
    print(item.name() + ": " + item.text());
}

Saving to a file

doc.save("output.xml");         // indented
doc.save("output.xml", false);  // not indented

Working with attributes

var node = doc.child("root").child("item");
print(node.attribute("id"));  // value of the id attribute

var attrs = node.attributes();
for (var a : attrs) {
    print(a.name + "=\"" + a.value + "\"");
}

Tree navigation

var node = doc.child("root").child("item");
var parent = node.parent();
var next = node.next_sibling();
var prev = node.prev_sibling();
