LDAP / Active Directory Plugin

Corporate environment: user authentication, directory search (WinLDAP)

RUEN

Home / Plugins / LDAP

Loading the plugin

loadPlugin("plugins/ldap.dll");

Implemented on the system library wldap32.dll. Works with Active Directory and any LDAP server (OpenLDAP, FreeIPA).

Authentication in Active Directory

Function for verifying user credentials (corporate authentication):

var ok = LDAPAuthenticate(server, port, user, password, [secure]);
ArgumentDescription
serverName or IP of the domain controller (e.g. "dc01.corp.local")
port389 — LDAP, 636 — LDAPS (TLS)
userUsername format, see below
passwordPassword
secure1 — TLS connection (recommended for passwords)

Allowed user formats:

  • UPN: "user@corp.local" — works over plain LDAP (389)
  • DN: "CN=Ivanov Ivan,OU=Users,DC=corp,DC=local"
  • DOMAIN\user: "CORP\user" — port 636 (LDAPS) recommended
// Plain LDAP, user in UPN format
if (LDAPAuthenticate("dc01.corp.local", 389, "ivanov@corp.local", "password"))
    print("Access granted");
else
    print("Access denied");

// Over TLS (LDAPS, port 636)
var ok = LDAPAuthenticate("dc01.corp.local", 636, "CORP\\ivanov", "password", 1);

Object interface

For searching and reading attributes, the LDAP() object is more convenient — the connection is opened once.

Creating the object

// No arguments — the connection is opened later by the open() method
var ld = LDAP();

// Immediately with a connection to the server
var ld = LDAP("dc01.corp.local");              // default port 389
var ld = LDAP("dc01.corp.local", 636);        // LDAPS (TLS)
var ld = LDAP("dc01.corp.local", 389, 1);      // 1 — TLS connection

Object methods

MethodArgumentsReturnsDescription

search arguments

ArgumentDescription
baseSearch base (DN). Empty string "" — directory root (rootDSE)
filterLDAP filter, e.g. "(&(objectCategory=person)(sAMAccountName=ivanov))"
attrsArray of attribute names (optional; default — all)
scope"base" / "one" / "sub" or number 0/1/2 (default "sub")

Result format

Each found record is a tuple with the key dn and attribute names:

{
    "dn":      "CN=Ivanov Ivan,OU=Users,DC=corp,DC=local",
    "sAMAccountName": "ivanov",
    "userPrincipalName": "ivanov@corp.local",
    "memberOf": #[ "CN=Domain Admins,...", "CN=IT,..." ]  // multi-valued attribute — array
}
  • Multi-valued attributes (memberOf, proxyAddresses, ...) — Array of strings
  • Binary attributes (objectSid, objectGUID, ...) — ByteArray

Examples

Searching users by department

var ld = LDAP("dc01.corp.local", 389);
if (!ld.bind("svc-script@corp.local", "password")) {
    print("Authentication error: " + ld.errorText());
    system.exit(1);
}

var users = ld.search("DC=corp,DC=local",
    "(&(objectCategory=person)(objectClass=user)(department=IT))",
    #[ "sAMAccountName", "mail", "displayName", "memberOf" ]);

print("Found: " + users.size());
for (var u : users)
    print(u.sAMAccountName + "  " + u.mail);

Getting the directory root (rootDSE)

var root = ld.search("", "(objectClass=*)", #[ "defaultNamingContext" ], "base");
if (root.size() > 0)
    var baseDN = root[0].defaultNamingContext;  // "DC=corp,DC=local"

Authentication + group membership check

// Step 1: authentication
if (!LDAPAuthenticate(server, 389, user, password)) {
    print("Invalid login or password");
    system.exit(1);
}

// Step 2: group check (direct memberOf)
var ld = LDAP(server, 389);
ld.bind(user, password);
var res = ld.search("DC=corp,DC=local",
    "(&(objectClass=user)(sAMAccountName=" + ld.escapeFilter(login) + "))",
    #[ "memberOf" ]);
var isAdmin = 0;
for (var g : res[0].memberOf) {
    if (g.pos("CN=Domain Admins") >= 0) { isAdmin = 1; break; }
}
ld.close();

Escaping user input

Always escape a value before substituting it into a filter — the characters *, (, ), \ break the filter syntax:

var name = ld.escapeFilter(userInput);   // "ab*(c)" -> "ab\2a\28c\29"
var r = ld.search(baseDN, "(&(objectCategory=person)(sAMAccountName=" + name + "))");

Complete example

loadPlugin("plugins/ldap.dll");

var server = "dc01.corp.local";
var login  = "ivanov@corp.local";
var pass   = "password";

// Authentication
if (!LDAPAuthenticate(server, 389, login, pass)) {
    print("Access denied");
    system.exit(1);
}
print("User authenticated");

// Connect and search
var ld = LDAP(server, 389);
if (!ld.isConnected()) { print(ld.errorText()); system.exit(1); }
ld.bind(login, pass);

var root = ld.search("", "(objectClass=*)", #[ "defaultNamingContext" ], "base");
var baseDN = root[0].defaultNamingContext;

var found = ld.search(baseDN,
    "(&(objectCategory=person)(objectClass=user)(sAMAccountName=" +
        ld.escapeFilter(login) + "))",
    #[ "dn", "displayName", "mail", "memberOf" ]);

for (var u : found) {
    print("DN: " + u.dn);
    print("Name: " + u.displayName);
    print("Email: " + u.mail);
}
ld.close();
