Set methods

// Explicit creation
var s1 = #set{1, 2, 3};
var s2 = #set{2, 3, 4};

// Auto-detection (simple values → set)
var s3 = #{1, 2, 3};

// difference/intersection modify the original set
// to avoid corrupting s1 — call clone() first:
print(s1.clone().difference(s2));        // {1} — s1 unchanged
print(s1.clone().intersection(s2));      // {2, 3}
print(s1);                              // {1, 2, 3}

Important notes

  1. concat, difference, intersection, subtract, merge modify the original value (they mutate) and return it. For a non-destructive result, call clone() first.
  2. DateTime methods work via automatic type coercion: the string "2026-06-28" or the number 1687900000 will be automatically converted to a date.
  3. sort() without arguments: numbers by value, strings lexicographically. With a function: sort(function(a, b) { return a < b })
  4. unique() sorts first, then removes duplicates. The order may change.
  5. forEach: for arrays — func(element), for tuples — func(key, value).
