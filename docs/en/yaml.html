yaml module

Working with YAML — parsing, serialization and validation (rapidyaml)

RUEN

Home / yaml

Access

The yaml module is available globally without uses:

print(typeName(yaml));  // object

Functions

FunctionDescription
yaml.parse(string)Parses a YAML string. Mappings → tuple, sequences → array
yaml.load(path)Parses a YAML file (UTF-8) → value
yaml.stringify(value)Value → YAML string (block style)
yaml.stringify(value, indent)YAML with the given indentation (spaces, 2 by default)
yaml.save(value, path, [indent])Serializes and writes to a file (UTF-8) → bool
yaml.validate(string)Checks whether the YAML is valid → true / false

Type mapping

YAMLScriptNote
mappingtuple #{"key": val}
sequencearray #[...]
stringstring
integer / floatint / double
true / falseint (1 / 0)Boolean values are stored as int
null / ~nullAn empty value is also null

Strings are always quoted on serialization, which guarantees correct re-parsing (including strings like "true", "1", etc.).

Examples

Parsing

var y = yaml.parse("name: Ivan\nage: 30");
print(y.name);  // Ivan
print(y.age);   // 30

Nested structures

var data = yaml.parse("server:\n  host: localhost\n  ports:\n    - 80\n    - 443");
print(data.server.host);      // localhost
print(data.server.ports[1]);  // 443

Serialization

var obj = #{"name": "Ivan", "age": 30, "tags": #[1, 2, 3]};
print(yaml.stringify(obj));   // block style, keys and strings quoted
print(yaml.stringify(obj, 4));// indent of 4 spaces

Files

var cfg = yaml.load("config.yaml");
cfg["debug"] = true;
yaml.save(cfg, "config.yaml");
print(yaml.validate("{bad: [}"));  // false
