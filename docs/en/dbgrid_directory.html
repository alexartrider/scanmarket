QDbDirectoryView — File explorer

Hierarchical or flat data view with folder navigation

RUEN

Home / QT / QDbDirectoryView

Description

QDbDirectoryView is a comprehensive widget for navigating hierarchical data (folders, trees). It includes:

  • Data table (QDbGridView) for displaying records
  • Navigation panel — "breadcrumbs" showing the current path
  • Mode switch — hierarchical or flat

The table must contain the fields:

  • rowid — unique row identifier
  • name — name
  • folder — 1 if a folder, 0 if a file/record
  • parent — ID of the parent folder (-1 for the root)

Examples

Basic explorer

var dir = qt.create("QDbDirectoryView", form);
dir.tableName = "files";
dir.directoryMode = true;
dir.viewMode = 0;  // Hierarchical
dir.columns = '[
    {"field":"rowid","caption":"ID","width":50},
    {"field":"name","caption":"Name","width":300},
    {"field":"folder","caption":"Type","width":80}
];
dir.align = "alClient";
dir.autoOpen = true;

Flat mode (no navigation)

var dir = qt.create("QDbDirectoryView", form);
dir.tableName = "employees";
dir.directoryMode = false;
dir.align = "alClient";
dir.open();

Event handling

// Double click — open a folder or file
dir.rowDoubleClicked = function(sender, row, rowId, isFolder) {
    if (isFolder) {
        sender.navigateTo(rowId);
    } else {
        print("Open file: \(rowId)");
    }
};

// Folder changed
dir.folderChanged = function(sender, folderId, folderName) {
    form.windowTitle = "Explorer — \(folderName)";
};

Manual navigation control

dir.open();                 // open
dir.navigateTo(42);         // enter folder 42
dir.navigateUp();           // go back
dir.navigateToRoot();       // to the root
var id = dir.currentRowId();  // current ID
dir.refresh();              // refresh
