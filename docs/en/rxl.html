Where to get a table object

WayExample
Form widget (recommended)In the JSON form specify a widget {"class":"QRXLWidget","name":"table1"}, then var grid = form.findWidget("table1");
Standalone windowvar w = dialog.newtable(owner, [title]); — an RXLMainWindow window (GUI)

Cell coordinates in the methods are 0-based (unlike Excel): row 1 = index 0.

Loading data (JSON)

grid.fromMemory(jsonText, tableName) — looks for the table with the given name in the "rxl" section of the document and fills the cells. Cell format: cells[row][column], each cell is {"t": text, "uc": column_span, "ur": row_span}; an empty cell is {}. A merge master has uc/ur > 0, subordinates have negative offsets to the master.

loadModule(file.normalize(file.join(file.dirname(system.getcommandline().app), "..", "scriptlib", "qtestlib.prg")));

var rxlDoc = json.stringify(#{
    "form": #{},
    "rxl": #[
        #{
            "name": "Price",
            "info": #{"maxCol": 2, "maxRow": 3, "viewGrid": 1},
            "data": #{
                "cells": #[
                    #[ #{"t": "Item"}, #{"t": "Price"}, #{"t": "Stock"} ],
                    #[ #{"t": "Mouse"}, #{"t": "450.5"}, #{"t": "yes"} ],
                    #[ #{"t": "Keyboard"}, #{"t": "1250"}, #{"t": "no"} ],
                    #[ #{"t": "Price total", "uc": 2, "ur": 0},
                       #{"t": "", "uc": -1, "ur": 0}, #{"t": "", "uc": -2, "ur": 0} ]
                ]
            }
        }
    ]
});
grid.fromMemory(rxlDoc, "Price");

Methods (from a script)

MethodDescription
grid.fromMemory(jsonText, tableName) / fromFile(path, tableName)Fill the table from JSON (0/1)
grid.setRow(r) / setCol(c)Current cell, 0-based
grid.getText() / setText(s)Read/write the current cell text
grid.getLastRow() / getLastCol()Last filled row/column
grid.getMaxRow() / getMaxCol()Maximum limits
grid.tableName() / setTableName(n)Table name
grid.mergeSelection() / unMergeSelection()Merge/split the selection (the selection is made via setSelection)
grid.insertRow() / insertCol() / deleteRows() / deleteCols()Structural operations
grid.exportExcel(path)Export to XLSX (numbers in text are converted automatically; merges are kept)
grid.exportPDF(path)Export to vector PDF (A4 pages, headers, page breaks — as in print preview)
grid.exportFile(path)Raster PNG/JPG/BMP/GIF (with several pages — name_1.png…)
grid.setRow(1); grid.setCol(2);
print(grid.getText());             // "450.5"
grid.setRow(3); grid.setCol(0);
grid.setText("4K monitor");

grid.exportExcel(file.join(dir, "price.xlsx"));
grid.exportPDF(file.join(dir, "price.pdf"));

The export can be verified by reading it back: the XLSX opens via qt.XlsxDocument() / xlsxedit.open().

Headless operation

Everything above works without a GUI session: the offscreen platform plugin is deployed, run with QT_QPA_PLATFORM=offscreen (see QT integration) and check the actual platform via qt.platformName().
