Loading plugins

Plugins are loaded via the global function loadPlugin:

// Load a plugin by file name (without the .dll/.so extension)
loadPlugin("archive7zip");

// With an alias
loadPlugin("archive7zip", "zip");

Returns true on successful load, false if not found.

Note: the uses keyword is only for built-in modules (str, math, file, datetime, etc.).

Arena safety (ScriptValueArena)

ScriptValueArena is a lifetime management system for fast script values. Values allocated with MakeTempValue live only on the current arena level. When ArenaLevelScope is invoked a new level is created; when leaving scopes the level is destroyed together with all values allocated on it.

Safety rule

Never return pointers/references to values allocated inside ArenaLevelScope.

If you created a value with MakeTempValue inside a scope, you must either:

  • Copy the value (Clone) before the scope ends
  • Or move the value to the heap via ScriptValue (shared_ptr)

Example of a mistake

// WRONG — the value is destroyed when leaving the scope
QScriptValueHandle HostObjectGet(QScriptContextHandle ctx, QScriptValueHandle obj)
{
    ArenaLevelScope scope{ctx->arena};
    QScriptValueHandle val = MakeTempValue(ctx, ScriptValue(int64_t(42)));
    return val; // val points to destroyed memory!
}

// RIGHT — copy the value before the scope ends
QScriptValueHandle HostObjectGet(QScriptContextHandle ctx, QScriptValueHandle obj)
{
    ArenaLevelScope scope{ctx->arena};
    QScriptValueHandle val = MakeTempValue(ctx, ScriptValue(int64_t(42)));
    return val->Clone(); // return a copy in permanent storage
}

Where this is critical

This issue affects plugin callback functions: HostObjectGetProperty, HostObjectCallMethod, HostObjectGetPropertyNames, HostObjectCall. The arena level is already managed by the calling code (PluginFuncWrapper, ExternalObjectWrapper::CallMethod); creating nested ArenaLevelScope in these functions is not allowed.

Symptoms

Violating this rule causes the FATAL: corrupted variant error — memory allocated on the arena is overwritten by other values after the level is destroyed, and the script engine tries to read invalid data.
