Windows Registry Plugin

Reading and writing the Windows registry — strings, numbers, binary data, multi-strings

RUEN

Home / Plugins / Registry

Loading the Plugin

loadPlugin("plugins/registry.dll");

Two ways to use it:

  • Object-oriented — open a key, read/write through methods, close it
  • Functional — single operations in one call

Functional Interface

For single operations — without opening/closing a key.

FunctionArgumentsReturnsDescription
RegistryOpenroot, path, [access], [create]RegistryInstanceOpens/creates a key. create=1 — create if missing
RegistryReadStringroot, path, namestringRead REG_SZ
RegistryReadIntroot, path, nameintRead REG_DWORD/QWORD
RegistryWriteStringroot, path, name, valueint (0/1)Write REG_SZ
RegistryWriteIntroot, path, name, valueint (0/1)Write REG_DWORD
RegistryDeleteValueroot, path, nameint (0/1)Delete a value
RegistryDeleteKeyroot, pathint (0/1)Delete an empty key
RegistryEnumKeysroot, pathArray<string>List of subkeys
RegistryEnumValuesroot, pathArray<Tuple>List of values with types
RegistryKeyExistsroot, pathint (0/1)Whether the key exists
RegistryValueExistsroot, path, nameint (0/1)Whether the value exists
// Direct string read
var path = RegistryReadString("HKLM", "SOFTWARE\\MyApp", "InstallPath");

// Direct number write
RegistryWriteInt("HKCU", "SOFTWARE\\MyApp", "Counter", 42);

// Existence check
if (RegistryKeyExists("HKLM", "SOFTWARE\\MyApp")) {
    print("Application is installed");
}

// Enumerate subkeys
var keys = RegistryEnumKeys("HKLM", "SOFTWARE\\Microsoft\\Windows\\CurrentVersion");
for (var k : keys) print(k);

Object Interface

Recommended for multiple operations — you open the key once.

Creation

// Open for reading
var reg = RegistryOpen("HKLM", "SOFTWARE\\ODBC\\ODBCINST.INI", "read");

// Open with write permissions
var reg = RegistryOpen("HKCU", "SOFTWARE\\MyApp", "all");

// Create the key if it does not exist
var reg = RegistryOpen("HKCU", "SOFTWARE\\MyApp", "all", 1);

Examples

Reading Installed Software

var reg = RegistryOpen("HKLM", "SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Uninstall");
if (reg.keyExists()) {
    var keys = reg.enumKeys();
    for (var k : keys) {
        var sub = RegistryOpen("HKLM", "SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Uninstall\\" + k);
        var name = sub.readString("DisplayName");
        if (!name.isnull()) print(name);
        sub.close();
    }
    reg.close();
}

Saving Application Settings

// Save
var reg = RegistryOpen("HKCU", "SOFTWARE\\MyApp\\Settings", "all", 1);
reg.writeString("theme", "dark");
reg.writeInt("width", 1280);
reg.writeInt("height", 720);
reg.writeMultiString("recent", #[
    "file1.txt",
    "file2.txt",
    "C:\\Documents\\data.csv"
]);
reg.close();

// Load
reg = RegistryOpen("HKCU", "SOFTWARE\\MyApp\\Settings");
if (reg.keyExists()) {
    var theme = reg.readString("theme");
    var w = reg.readInt("width");
    var h = reg.readInt("height");
    var files = reg.readMultiString("recent");
    reg.close();
}

Reading PATH with Variable Expansion

var reg = RegistryOpen("HKLM", "SYSTEM\\CurrentControlSet\\Control\\Session Manager\\Environment");
var path = reg.readExpandString("Path");
print(path);  // "C:\Windows\system32;C:\Windows;..." (variables expanded)
reg.close();

Binary Data

var reg = RegistryOpen("HKCU", "SOFTWARE\\MyApp", "read");
var data = reg.readBinary("RawData");
print(data.size());  // size in bytes
reg.close();

Deleting a Key Tree

var reg = RegistryOpen("HKCU", "SOFTWARE", "all");
reg.deleteTree("OldApp");  // deletes OldApp and all subkeys recursively
reg.close();

Determining the Value Type

var reg = RegistryOpen("HKCU", "SOFTWARE\\MyApp");
var values = reg.enumValues();
for (var v : values) {
    print(v.name + " = " + v.typeName);  // "theme = string", "width = dword"...
}
reg.close();
