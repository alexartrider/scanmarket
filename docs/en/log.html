Log module

Logging and output — available globally

Home / Log

Properties

PropertyTypeDescription
Log.IsWindowsTerminalboolWhether it is running in Windows Terminal
Log.consoleboolConsole window visibility (read/write). Shows/hides the window, not a settings object
Log.filePrefixstringLog file name prefix
Log.remoteFilePathstringPath to the remote log file
Log.localFilePathstringPath to the local log file
Log.writeToRemoteboolWrite to the remote file
Log.writeToLocalboolWrite to the local file

Setting Log.localFilePath or Log.remoteFilePath recursively creates the directory if it does not exist: logging starts immediately, with no manual file.mkdirrecursive. The default path (qt/bin/log) is still created automatically. The file name is <filePrefix>_DDMMYYYY.log (default log_DDMMYYYY.log).

Methods

MethodDescription
Log.rotate()Log file rotation
Log.print(args...)Output to the console
Log.trace(args...)Trace (TRACE level)
Log.error(args...)Error (ERROR level)
Log.format(args...)Formatting without output
Log.consoleInfo()Diagnostic snapshot of the console state (no modifications)
Log.refreshConsole()Re-checks the handles and reapplies output modes after child processes

Log.consoleInfo() and Log.refreshConsole() return a tuple with the keys: attached, visible, stdoutIsConsole, stderrIsConsole, outputRedirected, outputCodePage, inputCodePage, stdoutMode, stderrMode, vtProcessing, processedOutput, ansiColorsEnabled, lastError, refreshSucceeded.

Log.refreshConsole() does not call FreeConsole/AllocConsole and does not destroy the console: it safely re-obtains the output handle and enables VT only if it is actually supported. After launching child processes (which may share the parent console) this check diagnoses and restores the parent console state.

Examples

Log.print("Script started");
Log.trace("Debug:", variable);
Log.error("Error:", errorMessage);

Log.writeToLocal = true;
Log.filePrefix = "myscript";
Log.rotate();
