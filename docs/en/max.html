MAX Messenger plugin

Bot client for the MAX messenger — connecting, sending and receiving messages via Long Polling

RUEN

Home / Plugins / MAX

Overview

The max.dll plugin — an interface to the official MAX Bot API (the platform-api2.max.ru platform). It supports fetching bot information, sending text messages and reading incoming messages via Long Polling (GET /updates).

The bot Token is assigned when created on the business.max.ru platform (section "Chat bots" → ⋮ → Settings). The token is passed in the Authorization header — it is not embedded in the URL.

Dependencies

OpenSSL 3 is required: libssl-3-x64.dll, libcrypto-3-x64.dll (place them next to the binary).

Loading the plugin

loadPlugin("plugins/max.dll");

Creating an object

var mx = maxclient();

Connecting

var mx = maxclient();

if (!mx.connect("TOKEN_FROM_BUSINESS.MAX.RU")) {
    print("Error: \(mx.lastError())");
    return;
}

print("Connected as @\(mx.botUsername)");

Sending a message

By default send() sends a message to a user by their user_id (the ID can be taken from the sender_id field of an incoming message): POST /messages?user_id=.

The third argument mode sets the recipient type. If it equals "chat" or "channel", recipientId is interpreted as a chat_id (chat or channel): POST /messages?chat_id=. Any other value (or a missing argument) — sending to a user via user_id.

var mx = maxclient();
mx.connect("TOKEN");

// Send text to a user (user_id)
var ok = mx.send(12345678, "Hello!");
if (!ok) print("Error: \(mx.lastError())");

// Send to a chat/channel by chat_id
mx.send(987654321, "Hello, chat!", "chat");

Receiving messages (Long Polling)

By default the polling timeout is 30 seconds. MAX limits the use of Long Polling — for production environments a Webhook is recommended.

var mx = maxclient();
mx.connect("TOKEN");
mx.setTimeout(30);

// Waiting for a message (blocking call until the timeout)
var msg = mx.recv();
if (!msg.isnull()) {
    print("type:    \(msg.type)");
    print("from:    \(msg.sender_first_name) \(msg.sender_last_name) (id:\(msg.sender_id))");
    print("text:    \(msg.text)");
}

// Polling in a loop with a reply to "ping"
for (var i = 0; i < 5; i++) {
    var m = mx.recv();
    if (!m.isnull() && m.text == "ping") {
        mx.send(m.sender_id, "pong");
    }
}

SSL certificates

// Certificate chain verification is disabled by default
print(mx.setVerify());  // 0

// Enable verification
mx.setVerify(1);

// Own CA file (e.g. the Ministry of Digital Development certificate for max.ru domains)
mx.setCA("C:/certs/cacert.pem");

Full example: echo bot

loadPlugin("plugins/max.dll");

var mx = maxclient();
mx.setVerify(1);
mx.setTimeout(30);

// Token from business.max.ru → Chat bots → Settings
if (!mx.connect("TOKEN")) {
    print("Connection error: \(mx.lastError())");
    system.exit(1);
}

print("Bot @\(mx.botUsername) started. Send it something in MAX.");

while (mx.connected) {
    var msg = mx.recv();

    if (msg.isnull()) {
        continue;  // polling timeout — retry
    }

    print("\(msg.sender_first_name): \(msg.text)");

    if (msg.text == "/stop") {
        mx.disconnect();
        break;
    }

    // Reply to the sender
    mx.send(msg.sender_id, "You wrote: \"\(msg.text)\"");
}
