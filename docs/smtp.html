connect(host, [port], [useSSL])

Подключается к SMTP серверу. Выполняет TCP-соединение, опциональный SSL-хэндшейк и приветствие (EHLO/HELO).

АргументТипПо умолчаниюОписание
hoststring—Адрес сервера (домен или IP)
portint465Порт сервера
useSSLbooltrueSSL/TLS соединение. Если порт=465 — по умолчанию true
// SSL (порт 465)
smtp.connect("smtp.mail.ru", 465, true);

// STARTTLS (порт 587)
smtp.connect("smtp.gmail.com", 587, false);
smtp.starttls();

starttls()

Переключает соединение на TLS после начального подключения. Используйте если порт=587 и useSSL=false.

smtp.connect("smtp.gmail.com", 587, false);
smtp.starttls();  // TLS handshake
smtp.login("user@gmail.com", "password");

login(user, pass)

Авторизация на сервере. Пробует AUTH PLAIN, затем AUTH LOGIN.

smtp.login("user@mail.ru", "password");

send(from, to, subject, body, [isHtml])

Отправляет MIME-письмо с кодированием UTF-8.

АргументТипОписание
fromstringАдрес отправителя
tostringАдрес получателя
subjectstringТема письма
bodystringТекст письма
isHtmlboolHTML-формат тела (по умолчанию false)
// Простое письмо
smtp.send("from@mail.ru", "to@yandex.ru", "Тема", "Текст письма");

// HTML письмо
smtp.send("from@mail.ru", "to@yandex.ru", "HTML",
    "<h1>Привет!</h1><p>Это <b>HTML</b> письмо</p>", true);

attach(filename, data, [contentType], [contentId])

Добавляет вложение к следующему письму. Вызывайте attach() перед send().

АргументТипПо умолчаниюОписание
filenamestring—Имя файла для отображения
datastring / ByteArray—Путь к файлу или ByteArray
contentTypestring"application/octet-stream"MIME-тип
contentIdstring—Content-ID для inline-вложений
// Вложение из файла
smtp.attach("report.pdf", "C:\\docs\\report.pdf", "application/pdf");

// Вложение из ByteArray
var data = file.readbytes("image.png");
smtp.attach("image.png", data, "image/png");

// Inline-вложение (для HTML)
smtp.attach("logo.png", "logo.png", "image/png", "logo001");
smtp.send("from@mail.ru", "to@mail.ru", "HTML с картинкой",
    "<img src='cid:logo001'>", true);

print(smtp.attachments());  // 1

Примеры

Базовая отправка (SSL)

loadPlugin("plugins/smtp.dll");

var smtp = SmtpClient();
smtp.connect("smtp.mail.ru", 465, true);
smtp.login("user@mail.ru", "password");

smtp.send("user@mail.ru", "recipient@yandex.ru",
    "Тест", "Привет из скрипта!");

print(smtp.lastresponse());
smtp.disconnect();

Отправка с вложениями

loadPlugin("plugins/smtp.dll");

var smtp = SmtpClient();
smtp.connect("smtp.mail.ru", 465, true);
smtp.login("user@mail.ru", "password");

smtp.attach("photo.jpg", "C:\\Photos\\photo.jpg", "image/jpeg");
smtp.attach("data.csv", "C:\\Data\\report.csv", "text/csv");

smtp.send("user@mail.ru", "recipient@yandex.ru",
    "Отчёт", "Во вложении файлы");

print(smtp.attachments());  // 2
smtp.disconnect();

STARTTLS (порт 587)

var smtp = SmtpClient();
smtp.connect("smtp.gmail.com", 587, false);
smtp.starttls();
smtp.login("user@gmail.com", "app_password");
smtp.send("user@gmail.com", "dest@gmail.com", "Hi", "Hello!");
smtp.disconnect();

HTML письмо с inline-вложением

var smtp = SmtpClient();
smtp.connect("smtp.mail.ru", 465, true);
smtp.login("user@mail.ru", "password");

smtp.attach("logo.png", "C:\\logo.png", "image/png", "logo001");

var html = "<h1>Отчёт</h1>" +
    "<p>Вложение:</p>" +
    "<img src='cid:logo001' width='200'>";

smtp.send("user@mail.ru", "recipient@yandex.ru", "HTML отчёт", html, true);
smtp.disconnect();

Диагностика ошибок

var smtp = SmtpClient();
if (!smtp.connect("smtp.invalid.host", 465, true)) {
    print("Ошибка подключения: " + smtp.lastresponse());
}
smtp.connect("smtp.mail.ru", 465, true);
if (!smtp.login("wrong@mail.ru", "wrong_pass")) {
    print("Ошибка авторизации: " + smtp.lastresponse());
}
smtp.disconnect();
