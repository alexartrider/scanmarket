Загрузка плагина

loadPlugin("plugins/comport.dll");

Создание объекта

ComPort([name])

Создаёт объект COM-порта. Если указан name — именованный экземпляр ( singleton: повторный вызов с тем же именем возвращает тот же объект).

var port = ComPort();            // анонимный
var port = ComPort("myport");    // именованный

Методы

open([overlapped])

Открывает порт. Возвращает 1 при успехе, 0 при ошибке.

АргументТипПо умолч.Описание
overlappedbooltrueАсинхронный режим ввода/вывода

close()

Закрывает порт. Возвращает 1.

isopen()

Возвращает 1 если порт открыт, 0 — если закрыт.

write(data)

Записывает данные в порт.

АргументТипОписание
datastring / ByteArrayДанные для записи

Возвращает количество записанных байт.

writeline(text)

Записывает строку + \r\n. Возвращает количество записанных байт.

read([maxBytes], [asText])

Неблокирующее чтение из внутренней очереди.

АргументТипПо умолч.Описание
maxBytesint1024Максимум байт
asTextboolfalseВернуть строку вместо ByteArray

Возвращает ByteArray (или string), или null если нет данных.

readline([timeout])

Блокирующее чтение строки до \n.

АргументТипПо умолч.Описание
timeoutint3000Таймаут в мс

Возвращает строку или null при таймауте.

available()

Количество байт во внутренней очереди (неблокирующее).

getready()

Количество байт в аппаратном буфере (через ClearCommError).

clear()

Очищает все буферы (аппаратные + внутреннюю очередь). Возвращает 1.

clearrx() / cleartx()

Очищает только приёмный / передающий буфер.

listports()

Возвращает массив строк с именами доступных COM-портов.

var ports = ComPort().listports();
print(ports);  // ["COM1", "COM3", "COM5"]

setondata(callback)

Устанавливает callback, вызываемый при поступлении данных.

port.setondata(function(data) {
    print("Получено: " + data);
});

Примеры

Базовая работа

loadPlugin("plugins/comport.dll");

var port = ComPort();
port.port = 3;
port.baudrate = 9600;
port.bytesize = 8;
port.parity = port.PAR_NONE;
port.stopbits = port.STOP_1;

if (port.open()) {
    port.writeline("Hello");
    system.sleep(0.5);

    var response = port.readline(3000);
    if (response != null) {
        print("Ответ: " + response);
    }

    var data = port.read(1024, true);
    if (data != null) {
        print("Данные: " + data);
    }

    port.close();
}

Перечисление портов

var ports = ComPort().listports();
for (var p : ports) {
    print("Найден: " + p);
}

Именованные порты

// Создаёт порт с именем "meter"
var meter = ComPort("meter");
meter.port = 5;
meter.baudrate = 115200;
meter.open();

// Где-то в другом месте кода — получить тот же объект
var m = ComPort("meter");
m.writeline("READ");

Callback при приёме данных

var port = ComPort();
port.port = 3;
port.baudrate = 9600;
port.open();

port.setondata(function(data) {
    print("Пришло " + size(data) + " байт");
});

Программная чётность (7 бит)

var port = ComPort();
port.parity = port.PAR_PROGRAM7;
port.open();

// Запись: старший бит = бит чётности
port.write("Hello");

// Чтение: старший бит отбрасывается
