QodePoint, QodeSize, QodeRect — 2D-геометрия

RUEN

Главная / Геометрия

QodePoint — Точка

var p = QodePoint(10, 20);

Свойства

СвойствоТипОписание
xintКоордината X (чтение/запись)
yintКоордината Y (чтение/запись)

Методы

МетодОписание

negate() -> QodePointИнверсия знака координат

rotate(angle, center?) -> QodePointПоворот вокруг точки (радианы). center: QodePoint или (cx,cy)
lerp(target, t) -> QodePointЛинейная интерполяция к target (t: 0..1)

Пример

var p = QodePoint(10, 20);
p.add(5, 3).scale(2);          // QodePoint[30,46]
p.distance(QodePoint(0, 0));    // ~22.36
p.rotate(3.14159 / 2, 0, 0);   // поворот на 90°

var r = QodeRect(0, 0, 100, 200);

Примеры

// Разные конструкторы
var r1 = QodeRect(0, 0, 100, 200);
var r2 = QodeRect(QodePoint(0, 0), QodeSize(100, 200));
var r3 = QodeRect(QodePoint(0, 0), QodePoint(100, 200));

// Манипуляции
r1.inflate(10);                  // расширение на 10 со всех сторон
r1.offset(QodePoint(5, 5));      // смещение
r1.move(QodePoint(100, 100));    // перемещение в (100,100)

// Геометрия
var r4 = QodeRect(0, 0, 50, 50);
var r5 = QodeRect(25, 25, 75, 75);
r4.union(r5);                    // QodeRect[0,0,75,75]
r4.intersect(r5);                // QodeRect[25,25,50,50]
r4.contains(QodePoint(30, 30));  // true

// Разбиение на сетку
var cells = QodeRect(0, 0, 100, 100).split(2, 2);
// → [QodeRect[0,0,50,50], QodeRect[50,0,100,50],
//    QodeRect[0,50,50,100], QodeRect[50,50,100,100]]
